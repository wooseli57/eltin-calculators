## 4. 목록 스크립트 (`tools/build-calculators.py`)
- 분류 제목 `## 글자. 이름 [연결|1회성] (부제)` 읽기 → 분류에 `group: "연결"|"1회성"` 추가
- `### 세부 분류` 읽기 → 계산기에 `sub` 추가
- 새 열 `단계`, `함께 보이기` 읽기 → `step`, `also`(분류 글자 또는 태그 목록)
- 검사 추가: `함께 보이기`에 없는 분류 글자·태그가 있으면 오류
- `## 계산기 연결 흐름`·`## 번호 변경표`·`## 이전 번호 변경 기록` 절은 무시

## 5. 목록 페이지 (`index.html`)
- 분류 버튼: 맨 앞 "전체", 그다음 세 줄
  - 연결 계산: 메뉴 마진 · 온라인 상품 마진 · 월 마진
  - 1회성 계산: 인건비 · 운영비 · 판매 응용 · 광고
  - 레시피 · 조색 가이드 · 기본 도구
  - 각 줄 앞에 작은 글씨로 "연결 계산" / "1회성 계산" 표시, 버튼 글자는 분류 이름 그대로
- 연결 분류의 계산기는 단계 순서대로 `원가 1/6` 같은 단계 표시를 붙여 보여줌
- `### 세부 분류`는 분류 안에서 작은 제목으로
- `함께 보이기`: 해당 분류 목록 끝에 "함께 쓰면 좋은 계산기" 묶음으로 보여줌 (같은 파일로 링크)
- 375px 휴대폰 폭에서 버튼이 잘리지 않는지 확인

## 6. 공통 기능 (`assets/eltin-calc.js`·`.css`)
- 테마색: M 오렌지 #E0682B(옛 C), B 하늘색 #1F84D0(옛 M), **E 청록(새 색, 광고 하단 민트 #0E9692와 구별되는 색으로)**, L·O·S·A·R·G·T는 그대로. CLAUDE.md 7절 표도 갱신
- 연결 계산 머리말: 태그 옆에 단계 표시 (`M03 · 원가 3/6`)
- 연결 계산 결과 아래 "다음 단계 →" 버튼 (`data/calculators.json`의 같은 분류 다음 단계로, 다음 단계가 "준비 중"이면 회색). 결과값 넘기기는 다음 단계에서 계산기별로 정함
- `Eltin.ready` 판단은 지금처럼 목록 상태 기준
