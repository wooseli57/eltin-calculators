# R03 향료 사용량 계산기

상태: 사양 확정 (2026-11-24 채팅). 향료는 엘틴 퓨어 바닐라 익스트랙 1종으로 시작하고, 다른 향료는 `data/eltin-flavors.json`에 추가하면 화면에 자동으로 나타나게 만듦.
연결·단위 기준은 `docs/specs/color-flavor-links.md`를 함께 따름.

## 1. 향료 고르기

- 화면 맨 위에 향료 선택 칩(또는 드롭다운). 목록은 `data/eltin-flavors.json`의 `products`에서 읽음
- 지금은 1개: **엘틴 퓨어 바닐라 익스트랙** (M 마다가스카르 · U 우간다 · PX 파푸아뉴기니 공통 기준)
- 향료가 1개뿐이어도 선택 칸은 보여줌 (나중에 향료가 추가돼도 화면 구조가 그대로)
- 주소 `r03-flavor-dosage.html?flavor=vanilla&g=410` 으로 열 수 있음 (R01 엘틴 레시피의 "향 바꾸기" 버튼, 블로그 글)

## 2. 계산 방식 (탭 3개)

### 탭 ① 재료 양으로 계산 (기본)

입력 (모두 선택, 0이면 계산에서 뺌):
| 입력 | 기본값 |
|---|---|
| 밀가루 (g) | 250 |
| 우유·생크림 (ml) | 0 |
| 버터 (g) | 0 |
| 달걀 (개) | 0 |

사용 기준 (엘틴 퓨어 바닐라 익스트랙 상세페이지 "엘틴 퓨어 바닐라익스트랙 사용 기준" 표, 2026-11-24 확인):
| 주요 식재료 | 식재료 중량 | 권장 사용량 | ml |
|---|---|---|---|
| 밀가루 | 125g (약 1컵) | 1 tsp | 5 |
| 달걀 | 1알 (약 50~60g) | 3 tsp | 15 |
| 우유·생크림 | 250ml | 1 tsp | 5 |
| 버터 | 225g (2스틱) | 3 tsp | 15 |

계산:
1. 넣은 재료마다 기준량을 비례 계산 (예: 밀가루 250g → 10ml)
2. **권장량 = 밀가루·우유/생크림·버터 기준 중 가장 큰 값** (재료별 기준을 모두 더하면 지나치게 많아지므로 더하지 않음)
3. 달걀 기준은 밀가루·우유·버터를 하나도 넣지 않았을 때만 씀 (머랭·푸딩처럼 달걀이 주재료인 경우). 다른 재료와 함께 넣으면 달걀 줄에 "달걀 잡내를 더 잡고 싶으면 이 양까지 늘려도 돼요"로 참고만 표시
4. 결과 범위: 권장량의 0.5배 ~ 1배를 "은은하게 ~ 표준"으로, 1.5배를 "진하게"로 함께 보여줌

결과:
- lead: "바닐라 익스트랙은 10ml(2작은술) 넣으세요"
- big: ml 값
- rows: 재료별 기준량(근거가 된 재료 줄 강조), 은은하게·표준·진하게, 같은 양을 tsp·Tbsp·방울·g으로
- 비용: 선택한 용량 기준 1회 비용 (아래 가격표, 용량 칩 60ml·300ml·1000ml, 기본 60ml)

### 탭 ② 바닐라빈 바꾸기

- 입력: 레시피의 바닐라빈 개수 (기본 1)
- 기준: 상세페이지 "완벽한 대체 비율" — 바닐라빈 1개 = 익스트랙 3 Tbsp (약 45ml)
- 결과: "바닐라빈 1개 대신 익스트랙 45ml(3큰술)를 넣으세요" + tsp·방울·g·비용

### 탭 ③ 단위 바꾸기

- 입력: 양 + 단위 (방울·ml·tsp·Tbsp·g)
- 결과: 나머지 단위 모두 (방울은 정수, g은 소수 둘째 자리)
- 기준: 1방울 0.04ml, 1tsp 5ml, 1Tbsp 15ml, 바닐라 익스트랙 밀도 0.93g/ml (`data/eltin-flavors.json`의 `dropMl`·`spoonMl`·`density`)

## 3. 데이터 (`data/eltin-flavors.json`)

바닐라 익스트랙 항목을 아래처럼 채움. 다른 향료는 같은 형식으로 추가하면 선택 목록·계산·단위 변환이 그대로 동작해야 함.

```json
{
  "id": "vanilla",
  "name": "엘틴 퓨어 바닐라 익스트랙",
  "density": 0.93,
  "url": "https://eltin.imweb.me/shop_view/?idx=169",
  "sizes": [
    { "ml": 60, "price": 10900 },
    { "ml": 300, "price": 49000 },
    { "ml": 1000, "price": 150500 }
  ],
  "usage": [
    { "per": "flour",  "label": "밀가루",     "amount": 125, "unit": "g",  "ml": 5 },
    { "per": "milk",   "label": "우유·생크림", "amount": 250, "unit": "ml", "ml": 5 },
    { "per": "butter", "label": "버터",       "amount": 225, "unit": "g",  "ml": 15 },
    { "per": "egg",    "label": "달걀",       "amount": 1,   "unit": "개", "ml": 15, "fallbackOnly": true }
  ],
  "substitutes": [
    { "label": "바닐라빈 1개", "ml": 45 }
  ],
  "cautions": ["알코올이 들어 있어요. 굽지 않는 음료나 아이 간식에 넣을 때는 양을 줄이거나 바닐라 에센스를 고려하세요."]
}
```

- 가격 출처: 아임웹 상품 옵션 (M 60ml 10,900원 / 300ml 49,000원 / 1000ml 150,500원, 2026-11-24 확인). 가격이 바뀌면 이 값만 고침
- U·PX도 같은 사용 기준. 가격이 다르면 나중에 `sizes`를 제품별로 나눔
- 기존 `vanillaStandard`(R01 레시피용)는 이 `usage`와 같은 값이므로, R01도 이 항목을 읽게 정리해도 됨

## 4. 계산 기준과 주의 문구 (화면)

- "사용량은 엘틴 퓨어 바닐라 익스트랙 상세페이지의 사용 기준이에요. 취향과 레시피에 따라 조절하세요."
- "여러 재료가 함께 들어가면 가장 많이 필요한 재료 하나를 기준으로 계산했어요. 재료별 양을 모두 더하면 향이 지나치게 강해져요."
- "1방울은 0.04ml로 계산했어요 (바닐라 익스트랙 1방울 약 0.037g). 병 입구 모양, 온도, 병을 기울이는 각도, 남은 양에 따라 방울 크기가 달라질 수 있으니 참고용으로 쓰시고, 정확하게 하려면 계량스푼이나 저울을 써 주세요."
- 제품의 `cautions` 문구

## 5. 결정 메모

- 향료 선택은 처음부터 넣고, 바닐라 익스트랙 1종으로 시작 (다른 향료는 데이터만 추가)
- 여러 재료를 넣으면 더하지 않고 가장 큰 기준 하나를 씀. 달걀 기준(1알당 15ml)은 양이 커서 달걀이 주재료일 때만 씀
- 바닐라빈 대체(1개 = 45ml)와 단위 변환을 탭으로 포함
