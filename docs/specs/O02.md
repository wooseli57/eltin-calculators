# O02 카드수수료 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 연매출 | 원 | 비움 | 입력하면 우대수수료 구간 자동 판단, 판단된 구간을 입력칸 아래에 표시 ("영세 가맹점 (3억 원 이하)") |
| 한 달 카드매출 | 원 | 비움 | `Eltin.moneyInput()` |
| 체크카드 비중 | % | 0 | 칩: 0 / 30 / 50 + 직접 입력. 도움말: "모르면 0%로 두세요. 수수료가 가장 많이 나오는 쪽으로 계산돼요" |
| 일반가맹점 수수료율 | % | 2.2 | 연매출 30억 원 초과일 때만 표시. 예시값, 카드사 안내 요율로 바꾸도록 안내 |

## 계산식

- 구간 판단 (연매출 S)
  - S ≤ 3억: 영세 (신용 0.40%, 체크 0.15%)
  - 3억 < S ≤ 5억: 중소 (1.00%, 0.75%)
  - 5억 < S ≤ 10억: 중소 (1.15%, 0.90%)
  - 10억 < S ≤ 30억: 중소 (1.45%, 1.15%)
  - S > 30억: 일반 (입력한 요율을 신용·체크 모두에 적용)
- 체크 비중 c (0~1)
- 신용카드 매출 = 카드매출 × (1 − c), 체크카드 매출 = 카드매출 × c
- 월 카드수수료 = 신용 매출 × 신용 요율 + 체크 매출 × 체크 요율 (원 미만 버림)
- 연간 카드수수료 = 월 카드수수료 × 12
- 실제 수수료율 = 월 카드수수료 ÷ 카드매출 × 100
- 비교: 신용카드 100%일 때 / 체크카드 100%일 때 월 수수료

## 결과

- lead: "한 달 카드수수료는"
- big: 월 카드수수료
- rows: 적용 구간 / 신용카드 수수료(요율) / 체크카드 수수료(요율) / 실제 수수료율 / **1년이면**(total, 연간 수수료)
- tip: "모두 신용카드면 ○원, 모두 체크카드면 ○원이에요."
- tip: "간편결제(페이)나 PG사를 거치는 결제는 수수료가 다를 수 있어요."

## 계산 기준과 주의 문구

- ○○년 ○반기 우대수수료율 기준 (적용 시점 자동 표시)
- 주의 문구:
  > ○○년 기준이에요. 우대수수료율은 매년 2월·8월에 매출 구간이 다시 정해지고, 요율 자체도 주기적으로 다시 정해져요. 새로 개업한 가게는 처음에 일반 수수료가 적용된 뒤 나중에 차액을 돌려받아요. 참고용으로 사용하시고, 정확한 요율은 여신금융협회 '카드매출조회'(cardsales.or.kr)나 카드사에서 확인하세요.
- 신용카드 매출세액공제는 세금 계산기(M03)에서 다룸

## CONFIG (연도별)

```js
const CONFIG = {
  generalRateExample: 2.2,   // 예시: 금융위원회 보도자료의 일반가맹점 수수료율 예시 (확인 2026-11-23)
  checkChips: [0, 30, 50],
  rates: {
    2026: {                  // 금융위원회 2026.2.12 보도자료 "2026년 상반기 영세·중소가맹점 선정결과", 2026.2.14부터 적용 (확인 2026-11-23)
      tiers: [
        { max: 300000000,  name: "영세 가맹점 (3억 원 이하)",     credit: 0.40, check: 0.15 },
        { max: 500000000,  name: "중소 가맹점 (3억~5억 원)",      credit: 1.00, check: 0.75 },
        { max: 1000000000, name: "중소 가맹점 (5억~10억 원)",     credit: 1.15, check: 0.90 },
        { max: 3000000000, name: "중소 가맹점 (10억~30억 원)",    credit: 1.45, check: 1.15 },
        { max: Infinity,   name: "일반 가맹점 (30억 원 초과)",    credit: null, check: null }
      ]
    }
  }
};
```

- 다른 계산기(M04)도 같은 구간표를 쓰므로, 구간표는 `assets/eltin-calc.js`에 공통 데이터(`Eltin.cardTiers`)로 두는 것도 가능. 둘 중 관리가 쉬운 쪽을 선택하되, 한 곳에서만 관리할 것.

## 결정 메모

- 연매출 입력 → 구간 자동 판단
- 체크카드 비중 기본 0% (보수적)
- 간편결제 수수료·카드 매출세액공제는 제외, 안내만
