# M04 실수령 정산 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 한 달 카드매출 | 원 | 비움 | |
| 한 달 현금·계좌이체 매출 | 원 | 0 | |
| 한 달 배달앱 매출 | 원 | 0 | 음식값 기준 (배달팁 제외) |
| 한 달 배달 건수 | 건 | 0 | 배달 매출이 있을 때만 표시 |
| 카드 연매출 구간 | 선택 | 영세 (3억 원 이하) | O02와 같은 구간표, 일반 선택 시 요율 입력칸 표시(예시 2.2%) |
| 배달 수수료 설정 | 접는 칸 | 중개 7.8%, 결제 3%, 건당 배달비 비움, 부가세 포함 켜짐 | C03과 같은 예시 기본값 |

- 체크카드 비중은 O02와 같이 기본 0%로 계산하고, 접는 칸 안에서만 바꿀 수 있게 함.

## 계산식

- 총매출 = 카드매출 + 현금·계좌이체 매출 + 배달앱 매출
- 카드수수료 = O02 계산식 (구간 요율, 체크 비중 0% 기본)
- 배달 수수료 = 배달앱 매출 × (중개율 + 결제율) × vat (vat = 1.1 또는 1.0)
- 배달비 = 건당 배달비 × 배달 건수
- 실수령액 = 총매출 − 카드수수료 − 배달 수수료 − 배달비
- 수수료 비율 = (카드수수료 + 배달 수수료 + 배달비) ÷ 총매출 × 100
- 각 금액 원 미만 버림

## 결과

- lead: "한 달에 통장에 들어오는 돈은"
- big: 실수령액
- rows: 총매출 / 카드수수료 / 배달 수수료 / 배달비 / 매출 대비 수수료 비율 / **실수령액**(total)
  - 0원인 줄은 숨김
- tip: "부가세·소득세, 광고비, 쿠폰 부담분은 빠진 금액이에요. 세금은 세금 계산기(M03)에서 확인하세요."

## 계산 기준과 주의 문구

- 카드수수료는 ○○년 우대수수료율 기준, 배달 수수료는 입력한 요율 기준
- 주의 문구 (O02 + C03 합침):
  > ○○년 기준이에요. 카드 우대수수료율은 매년 2월·8월에 매출 구간이 다시 정해지고, 배달앱 수수료와 배달비는 앱마다 다르며 가게의 매출 구간, 가게와 손님 사이의 거리, 앱의 정책에 따라 수시로 바뀌어요. 배달 수수료 기본값은 예시예요. 참고용으로 사용하시고, 정확한 금액은 카드사·여신금융협회와 각 배달앱 정산서를 확인하세요.

## CONFIG

- 카드 구간표: O02와 같은 데이터를 사용 (한 곳에서만 관리)
- 배달 기본값: C03과 같은 값 (`brokerRate: 7.8`, `payRate: 3.0`, 예시)

## 결정 메모

- 입력은 카드·현금·배달 매출 + 카드 구간 + 배달 설정(접는 칸)
- 세금·광고비·쿠폰은 제외, 안내만
