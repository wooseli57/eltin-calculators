## 2. 메뉴 이름 칸 (C01·C02·C03·C05)
- 입력 카드 맨 위에 `메뉴 이름` 텍스트 칸 1개 (placeholder: "예: 아메리카노", 비워도 됨)
- 결과 문장에 반영: 이름이 있으면 "아메리카노 1개에 들어가는 재료비는", 없으면 지금처럼 "메뉴 1개에 들어가는 재료비는"
- 결과 복사 문구 맨 앞에도 메뉴 이름: "[메뉴별 원료비용] 아메리카노: …"
- [처음으로]를 누르면 메뉴 이름도 비움
- C04 배달비용은 주문 1건 기준이라 메뉴 이름 칸을 넣지 않음
