# 계산기별 상세 사양

채팅에서 계산식·입력·문구를 확정한 계산기는 여기에 `<태그>.md` 파일로 저장합니다 (예: `L01.md`).
Claude Code는 계산기를 만들 때 해당 파일이 있으면 그 내용을 우선으로 따릅니다.

사양 파일 형식:

```
# L01 인건비 계산기
## 입력      (항목, 단위, 기본값)
## 계산식    (공식, 반올림 방식)
## 결과      (한 문장, 큰 숫자, 내역 표 항목)
## 계산 기준 (화면 하단 안내 문구)
## CONFIG    (값, 출처, 확인 날짜)
## 결정 메모 (채팅에서 정한 내용 요약)
```
