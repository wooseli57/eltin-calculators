# B01 사업장 월 원가 계산기

상태: 사양 확정 (2026-11-25 채팅). 파일 `b01-monthly-cost.html`, 테마 B(하늘색). (2026-11-25 재구조화: 옛 C06 → B01. 매장·온라인 탭 구조는 `docs/specs/B-monthly.md` B01 절이 우선)

## 목적

M01~M04는 메뉴 1개 기준(가격 정하기·메뉴 마진용)이고, B01은 사업장 전체의 **한 달 원가**를 구해요.
메뉴별 원가를 모두 더하는 방식은 메뉴가 많으면 불편하므로, 사장님이 이미 알고 있는 **한 달 금액**(또는 매출 대비 %)을 넣는 방식으로 만들어요.

## 입력 (5개)

| 항목 | 기본값 | 입력 방식 | 안내 (hint) |
|---|---|---|---|
| 월 매출 | 15,000,000원 | 금액 (`Eltin.moneyInput`) | 포스·카드 매출 합계 (부가세 포함 금액 그대로) |
| 원료 구입비 | 30% | [금액] [매출의 %] 전환 | 거래처 명세서·카드 내역의 한 달 재료 구입액 |
| 자재 구입비 (컵·박스 등) | 5% | [금액] [매출의 %] 전환 | 포장 자재 한 달 구입액 |
| 배달 비용 (중개수수료 + 배달비) | 0원 | [금액] [매출의 %] 전환 | 배달앱 정산서의 수수료·배달비 합계. 배달을 안 하면 0 |
| 폐기·손실 (참고) | 3% | % 전용 | 구입한 원료 중 버리는 비율 (합계에 더하지 않음) |

- 각 항목의 [금액]/[매출의 %] 전환은 작은 seg 버튼. % 모드는 `월 매출 × %`로 금액 환산해서 칸 아래에 "약 ○원" 표시
- 금액 모드에서는 칸 아래에 "매출의 ○%" 표시
- 월 매출이 0이면 % 모드 항목은 계산하지 않고 "월 매출을 넣으면 %로 계산돼요" 안내

## 계산

- 원료 = 금액 또는 매출 × %
- 자재 = 금액 또는 매출 × %
- 배달 = 금액 또는 매출 × %
- **월 원가 합계 = 원료 + 자재 + 배달**
- 원가율 = 월 원가 합계 ÷ 월 매출 × 100
- 원가를 빼고 남는 돈 = 월 매출 − 월 원가 합계 (고정비·인건비를 빼기 전 금액)
- 폐기·손실 금액(참고) = 원료 × 손실 %  → **합계에 더하지 않음**. 한 달 구입액에는 버린 재료가 이미 들어 있어서 더하면 두 번 계산됨

## 결과

- lead: "한 달 원가는"
- big: 월 원가 합계
- 원그래프 (`Eltin.donut`): 원료 / 자재 / 배달 / 남는 돈 (남는 돈은 마지막, `profitLast: true`), 가운데 "원가율 ○%"
- rows: 원료 구입비 (매출의 ○%) / 자재 구입비 (○%) / 배달 비용 (○%) / **월 원가 합계 (원가율 ○%)** / 원가를 빼고 남는 돈
- tip:
  - "구입한 원료 중 약 ○원어치가 버려지고 있어요. 폐기를 1%p 줄이면 한 달 약 ○원을 아낄 수 있어요." (원료 × 1%)
  - 원가율 40% 초과: "원가율이 높은 편이에요. 메뉴별 원가(M04)와 판매가(S01)을 점검해 보세요." (기준 문구는 일반 안내이며 업종마다 다름을 계산 기준에 명시)
  - "인건비·월세 등 고정비는 월 손익 계산기(B07)에서 함께 넣고, 남는 돈에서 빼면 한 달 이익이에요."

## 계산 기준 (화면 하단)

- 한 달 구입액 기준이에요. 재고를 많이 사 두거나 써 버린 달은 실제 사용량과 달라질 수 있어요 (재고가 크게 변하지 않는 달 기준).
- 폐기·손실은 이미 구입액에 들어 있어 합계에 더하지 않고 참고로만 보여줘요.
- 매출과 구입비는 같은 기준(둘 다 부가세 포함 또는 둘 다 제외)으로 넣어 주세요.
- 원가율 기준(40%)은 일반적인 참고값이며 업종·메뉴 구성에 따라 달라요.
