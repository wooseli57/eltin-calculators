# R07 틀 크기 변환 계산기 (+ 공통 케이크 틀 크기표)

상태: 확정 (2026-11-23 채팅에서 결정)

## 0. 공통 케이크 틀 크기표 — `Eltin.pans` (R04·R01·R07·S07 공용)

`assets/eltin-calc.js`에 공통 데이터로 둡니다.

```js
pans: [
  { id: 'mini', name: '미니', diameter: 12, serves: '2~4인', editable: true },  // 가게마다 10~12cm → 고르면 지름 칸 표시(수정 가능)
  { id: '1',    name: '1호',  diameter: 15, serves: '4~6인' },
  { id: '2',    name: '2호',  diameter: 18, serves: '6~8인' },
  { id: '3',    name: '3호',  diameter: 21, serves: '8~10인' },
  { id: '4',    name: '4호',  diameter: 24, serves: '10~12인' }
]
// 지름: 국내 판매 원형틀 1호 150ø, 2호 180ø, 3호 210ø 기준, 호수당 3cm (확인 2026-11-23)
// 인분: 지름별 일반적인 인분 안내 참고 (확인 2026-11-23), 화면에는 "대략"으로 표시
```

## 1. 입력

| 항목 | 기본값 | 비고 |
|---|---|---|
| 원래 틀 모양 | 원형 | seg: [원형] [사각] |
| 원래 틀 크기 | 1호 | 원형: 호수 칩(미니·1·2·3·4호) + "지름 직접 입력", 사각: 가로·세로(cm) |
| 바꿀 틀 모양 | 원형 | |
| 바꿀 틀 크기 | 2호 | |
| 높이 (선택) | 비움 | 두 틀 모두 넣으면 높이 비율 반영 (cm) |
| 원래 반죽 총무게 (선택) | 비움 | g |

- 미니를 고르면 지름 칸(기본 12cm)이 나타나 수정 가능.
- 처음 열면 "1호 → 2호" 예시로 결과가 바로 보임.

## 2. 계산

- 원형 넓이 = π × (지름 ÷ 2)², 사각 넓이 = 가로 × 세로
- 재료 배수 = 바꿀 틀 넓이 ÷ 원래 틀 넓이 (× 바꿀 높이 ÷ 원래 높이, 두 높이 모두 있을 때)
- 바꿀 틀 반죽 무게 = 원래 반죽 총무게 × 배수 (입력했을 때)
- 배수는 소수 2자리, %는 정수

## 3. 결과

- lead: "재료를 이만큼 바꾸세요"
- big: "1.44배" (+ "144%")
- rows: 원래 틀 넓이(cm²) / 바꿀 틀 넓이(cm²) / 높이 비율(입력 시) / 바꿀 틀 반죽 무게(입력 시) / 대략 인분(원형 호수일 때)
- tip: "재료별 양은 내 레시피 분량 계산기(R04)에서 배수 ○배로 바로 계산할 수 있어요." (R04 링크)
- tip: "틀이 커지면 굽는 시간이 늘어나요. 속까지 익었는지 꼬치로 확인하세요."

## 4. 계산 기준

- 넓이 비율로 재료를 늘리거나 줄여요 (같은 높이로 구울 때)
- 틀 크기와 인분은 일반적인 기준이며 가게·제품마다 다를 수 있어요

## 결정 메모

- 1호 기준으로 시작 (기본 예시 1호 → 2호)
- 미니는 12cm 기본 + 직접 입력
- 원형·사각 모두 지원, 높이는 선택
