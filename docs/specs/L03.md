# L03 퇴직금 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 계산 방식 | 선택 | 간단 계산 | seg: [간단 계산] [정확 계산] |
| 입사일 | 날짜 | 비움 | `<input type="date">` |
| 퇴사일 | 날짜 | 오늘 | 마지막 근무일의 다음 날 기준 안내 |
| 최근 월급 | 원 | 비움 | 간단 계산일 때. 세전, 매달 받는 금액 |
| 퇴사 전 3개월 급여 | 원 × 3칸 | 비움 | 정확 계산일 때 |
| 1년 상여금 | 원 | 0 | 선택 입력 |
| 1년 연차수당 | 원 | 0 | 선택 입력 |
| 주 15시간 이상 근무 | 체크 | 켜짐 | |

## 계산식

- 재직일수 = 퇴사일 − 입사일 (일)
- 대상: 재직일수 ≥ 365 이고 주 15시간 이상
- 3개월 기간 = 퇴사일 직전 3개월의 달력 일수 (퇴사일 3개월 전 같은 날부터 퇴사일 전날까지, 89~92일)
- 3개월 급여 총액
  - 간단 계산: 최근 월급 × 3
  - 정확 계산: 3칸 합계
- 1일 평균임금 = (3개월 급여 총액 + 1년 상여금 × 3/12 + 1년 연차수당 × 3/12) ÷ 3개월 기간 일수
- 퇴직금 = 1일 평균임금 × 30 × (재직일수 ÷ 365), 원 미만 버림

## 결과

- 대상일 때 lead: "예상 퇴직금은" / big: 퇴직금
- rows: 재직기간(○년 ○개월, ○일) / 3개월 급여 총액 / 상여금·연차수당 반영분 / 1일 평균임금 / **퇴직금**(total)
- 대상이 아닐 때 lead: "퇴직금 대상이 아니에요" / 이유 한 줄
  - 1년 미만: "1년 이상 일해야 퇴직금이 생겨요 (지금 ○개월)"
  - 주 15시간 미만: "4주 평균 주 15시간 미만으로 일했다면 퇴직금 대상이 아니에요"
- tip: "퇴직금은 퇴사일로부터 14일 안에 지급해야 해요."
- tip (간단 계산일 때): "최근 3개월 급여가 매달 다르면 정확 계산을 써주세요."

## 계산 기준

- 1일 평균임금 = 퇴사 전 3개월 급여 ÷ 그 기간 일수 (상여금·연차수당은 1년 치의 3/12 반영)
- 1일 평균임금이 1일 통상임금보다 적으면 통상임금으로 계산해야 해요 (이 계산기는 반영하지 않음)
- 퇴직금에서 떼는 퇴직소득세는 반영하지 않았어요
- 공통 주의 문구 (CLAUDE.md 6항)

## CONFIG

```js
const CONFIG = {
  bonusShare: 3 / 12   // 상여금·연차수당 반영 비율 (근로기준법 평균임금 산정 실무 기준)
};
```

(L03은 매년 바뀌는 요율이 없지만, 법령 개정으로 기준이 달라질 수 있으므로 공통 주의 문구는 그대로 표시)

## 결정 메모

- 기본은 간단 계산(최근 월급 하나), 정확 계산은 3개월 급여 각각 입력
- 상여금·연차수당 입력칸 포함 (선택)
- 통상임금 비교는 안내 문구로만
- 근속기간은 입사일·퇴사일 날짜 입력
