# S08 견적 계산기 (주문 케이크)

상태: 확정 (2026-11-23 채팅에서 결정)

가게마다 재료비·작업시간이 크게 다르므로, **1호 기준 재료비를 사장님이 넣으면 다른 크기는 넓이 비율로 자동 계산**합니다. 틀 크기표는 R07 사양 0절의 공통 데이터 `Eltin.pans`를 사용합니다.

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 크기 | 선택 | 1호 | 칩: 미니·1호·2호·3호·4호 (미니 고르면 지름 칸, 기본 12cm) |
| 단수 | 선택 | 1단 | 칩: 1단·2단·3단. 위로 한 호수씩 작아짐 (2단 2호 = 2호 + 1호, 3단 3호 = 3호 + 2호 + 1호). 가장 작은 단이 미니보다 작아지면 선택 불가 |
| 디자인 난이도 | 선택 | 기본 | seg: [기본] [보통] [어려움]. 고르면 작업시간 예시값 채움 |
| 예상 작업시간 | 시간 | 1.5 | 예시: 기본 1.5 / 보통 2.5 / 어려움 4. 직접 수정 가능 (0.5 단위) |
| 1호 기준 재료비 | 원 | 비움 | placeholder: "예: 시트+크림+과일+장식+상자". `Eltin.moneyInput()` |
| 추가 장식비 | 원 | 0 | 레터링, 사진 인쇄, 생화 등 |
| 시간당 인건비 | 원 | 해당 연도 최저임금 | 수정 가능 |
| 목표 이익률 | % | 30 | 예시값, 칩: 20 / 30 / 40 |

## 계산

- 넓이 비율(단) = (그 단 지름 ÷ 15)²
- 재료비 = 1호 기준 재료비 × 각 단 넓이 비율의 합 + 추가 장식비
- 인건비 = 예상 작업시간 × 시간당 인건비
- 원가 = 재료비 + 인건비
- 최소 견적 = 원가 × 1.1 (부가세 포함, 이보다 낮으면 손해), 100원 단위 올림
- 권장 견적 = 원가 ÷ (1 − 목표 이익률) × 1.1, 1,000원 단위 올림
- 목표 이익률 ≥ 100%이면 "100% 미만으로 넣어주세요"
- 대략 인분 = 가장 아래 단 호수의 인분 (2단 이상은 각 단 인분 합으로 "약 ○~○인")

## 결과

- lead: "권장 견적은"
- big: 권장 견적 (+ 작은 글씨 "최소 ○원")
- **원형 차트** (CLAUDE.md 4항 `Eltin.donut()`): 권장 견적 = 재료비 / 인건비 / 부가세 / 이익. 가운데 "이익 ○원"
- rows: 케이크 구성(예: 2단 · 2호 + 1호) / 재료비 / 인건비(○시간 × ○원) / 최소 견적 / **권장 견적**(total) / 대략 인분
- tip: "재료비는 1호 기준을 넓이 비율로 늘린 값이에요. 실제 재료가 더 들면 추가 장식비에 넣어주세요."

## 계산 기준과 주의 문구

- 크기별 재료비는 1호 기준 × 넓이 비율, 견적은 부가세 포함
- 시간당 인건비 기본값은 ○○년 최저임금 (연도별 자동)
- 주의 문구:
  > 예상 견적이에요. 작업시간·이익률 기본값은 예시이니 우리 가게 기준으로 바꿔 넣으세요. 인건비 기본값은 ○○년 최저임금이며 매년 바뀌어요.

## 결정 메모

- 1호 기준 재료비 입력 → 크기·단수별 넓이 비율로 자동 계산
- 처음 열면 1호 · 1단 · 기본 선택
- 작업시간 예시 1.5 / 2.5 / 4시간, 목표 이익률 예시 30%
- 최소 견적(손해 안 보는 선)과 권장 견적을 함께 표시
