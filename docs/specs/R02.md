# R02 색소 사용량 계산기 사양

상태: 사양 확정 (2026-11-27 채팅). 파일 `r02-color-dosage.html`, 회원 전용(`data-access="member"`).
`docs/specs/color-flavor-links.md`의 R02 부분(권장 사용량 `dosage`, `level` 1·2·3)은 이 문서로 대체. 방울 기준(2절)은 그대로 따름.

## 0. 결정 (대표 2026-11-27)
- 사용량 기준은 **생크림 측정표** (`data/color-chips.json`의 생크림: 10g당 1·2·4·6·8·10방울 단색 48색, 2·3색 조합). 바탕별 권장 사용량 자료는 따로 만들지 않음.
- 생크림이 아닌 재료를 고르면 **"생크림 기준이라 다른 재료에서는 색이 다르게 나올 수 있다"**는 안내를 결과 바로 아래에 표시.
- **음료·젤리는 물 조색 데이터 기준** (대표 결정 2026-11-27): 색은 물 측정표, 색소 양은 측정 희석 비율 그대로 **1/100** (음료·젤리 100ml당 색소 1ml). 안내에 물 색 추출 조건과 "정수 기준이라 다른 재료면 색이 다르게 나올 수 있다"를 함께 표시. 아래 2-1절.

## 1. 입력 (위에서 아래로)
1. **재료**: `data/color-bases.json`의 식품용 바탕 중 초콜릿을 뺀 것 (생크림·버터크림·머랭·반죽·아이싱·쌀가루·음료·젤리·설탕). 기본 생크림. **초콜릿은 목록에서 뺌** (대표 결정 2026-11-27)
2. **양**: g (음료는 ml, 1ml = 1g으로 계산). 기본 300
3. **색**: 48색 색 점(그룹별: 진한1 · 진한2 · 진한3 · 계절 스페셜). 기본 노랑
   - 주소로 배합(`mix`)을 받으면 색 점 대신 받은 배합을 보여주고 [다른 색 고르기]로 단색 선택으로 돌아감
4. **원하는 진하기**: 고른 색의 생크림 측정 견본 6칸(10g당 1·2·4·6·8·10방울)을 색 칩으로 보여주고 하나를 고름. 기본 4방울. 배합을 받았을 때는 이 칸 대신 [절반 · 그대로 · 2배] (기본 그대로)
5. **색소 용량**(비용 계산): [20g · 50g · 1kg] — `data/eltin-colors.json`의 가격. 기본 20g

## 2. 계산
- 10g당 방울(d) → 내 양 방울 = d × 양 ÷ 10 (색마다, 배합은 색별로, 배율 적용)
- g = 방울 × `dropMl`(0.04) × `density`(1.05), 소수 둘째 자리. 방울은 정수 반올림
- 비용 = g × (용량 가격 ÷ 용량 g), 원 단위 반올림. 배합은 합계도
- 예상 색: 단색은 측정 견본 그대로, 배합은 측정 칩 그대로 (`ColorData.lookup`). 배율을 바꿔 측정 칩이 없으면 견본 대신 "측정 자료가 없는 진하기라 예상 색은 보여주지 않아요"

## 2-1. 음료·젤리 (물 기준 모드)
- 재료가 음료(`drink`)나 젤리(`jelly`)면 물 기준 모드로 바뀜
- 색: 기본 8색(진한1) 단색, 또는 주소로 받은 배합(`mix`, 비율). 진하기 칸(생크림 견본 6칸·배율)은 숨김
- 색소 총량(ml) = 양(ml, 젤리는 g = ml로) ÷ 100. 배합은 비율대로 나눔 (예: `YE:3,GR:1` → 노랑 3/4, 초록 1/4)
- 방울 = ml ÷ 0.04 (정수 반올림), g = ml × 1.05, 비용은 2절과 같음
- 예상 색: 배합이면 물 측정 칩(`ColorData.lookup('water', mix)`), 단색이면 색소 대표 컬러코드(라벨 "색소 대표색")
- 예: 음료 800ml · 노랑 → 색소 8ml = 200방울 · 8.40g · 20g 기준 1,428원

## 3. 결과 카드
- lead: "노랑 120방울(5.04g)을 넣으세요" (배합이면 "색소 2가지를 이만큼 넣으세요")
- big: 총 g, 작은 글씨로 총 방울
- 예상 색 견본 + 라벨 **"생크림에 섞었을 때 색"** (물 기준 모드는 "정수에 묽혔을 때 색")
- **재료 안내 (재료가 생크림이 아닐 때만, 견본 바로 아래)**: "생크림에 섞어 측정한 색을 기준으로 계산했어요. ○○(재료 이름)에서는 재료 색과 성질 때문에 색이 다르게 나올 수 있어요."
- rows: 색별 방울 · g · 비용, 합계 비용 (색소 ○g 용량 기준)
- **물 기준 안내 (음료·젤리일 때, 견본 바로 아래)**: "정수에 색소를 1/100로 묽혀 측정한 색을 기준으로 계산했어요. 묽힌 액 0.015ml를 고광택 인화지에 떨어뜨려 말린 뒤 스캔해 색을 뽑았어요. 음료·젤리 재료에 따라 색이 다르게 나올 수 있어요."
- 버튼: 재료가 생크림이면 "색이 생각보다 연하거나 진한가요? 농도 조절 →" G03 (`?mix=…&g=…`), `from`이 있으면 "← 레시피로 돌아가기"
- [결과 복사]: "엘틴 색소 · 생크림 300g · 노랑 120방울(5.04g) · 약 857원"

## 4. 방울 ↔ g 바꾸기 (결과 아래 작은 카드)
- "다른 레시피에 적힌 양 바꾸기": 방울 또는 g 하나를 넣으면 반대 단위 (같은 dropMl·density)

## 5. 계산 기준 (화면)
- 색 추출 방법 (재료에 맞는 것만): 물 기준 모드는 "정수에 색소를 1/100로 묽혀 정한 비율로 섞고, 0.015ml 한 방울을 Kodak 고광택 인화지에 떨어뜨려 말린 뒤 스캔(600dpi)해 RGB 추출" / 그 밖에는 생크림 10g에 엘틴푸드칼라를 떨어뜨려 완전히 섞은 뒤 가장 비슷한 색의 RGB 기록 (엘틴 컬러칩북)
- 방울 기준 문구(color-flavor-links 2절 그대로): "1방울은 0.04ml로 계산했어요 (색소 1방울 약 0.042g). 병 입구 모양, 온도, 병을 기울이는 각도, 남은 양에 따라 방울 크기가 달라질 수 있으니 참고용으로 쓰시고, 정확하게 하려면 저울로 g을 재 주세요."
- 가격: 쇼핑몰 가격 기준과 확인 날짜 (`eltin-colors.json`)

## 6. 주소 파라미터 (모두 선택, 잘못되면 기본값)
| 파라미터 | 예 | 뜻 |
|---|---|---|
| `base` | `buttercream` | 재료 id (`chocolate`이나 모르는 값이면 생크림) |
| `g` / `ml` | `500` | 양 |
| `color` | `YE` | 색 약자 (color-chips.json `colors`) |
| `level` | `6` | 10g당 방울 (1~10, 3·5·7·9는 G-color.md의 중간값 견본) |
| `mix` | `YE:1,OR:3` | 10g당 배합 (G02·G03에서). 있으면 color·level 무시 |
| `from` | `r01:2` | 돌아가기 링크 |

- **R01 수정**: 바탕이 `chocolate`인 레시피(18 케이크팝)는 [이 양에 색 입히기] 버튼을 보여주지 않음
- G07 물 색 배합에서 R02로 보내는 버튼은 두지 않음 (대표가 필요성 미정이라 보류)
- **보내는 쪽 수정**: G02 "이 배합으로 양 계산" → `r02-color-dosage.html?mix=<배합>&g=<G02의 내 생크림 양>` (지금은 파라미터 없이 열림). R01은 지금처럼 `base`·`g`·`from`.

## 7. 데이터
- `data/eltin-colors.json` `products`에 진한 단품 용량·가격 채움: 20g 3,400원 (idx 95), 50g 7,900원 (idx 96), 1kg 99,000원 (idx 97) — 아임웹 상품 기본가, 2026-11-27 채팅 확인. 옵션별 가격이 다르면 사용자에게 확인
- 색 목록·견본은 `data/color-chips.json`만 사용 (중복 데이터 만들지 않음)

## 8. 확인
- 생크림 300g · 노랑 · 4방울 → 120방울 · 5.04g · 20g 기준 857원 (5.04 × 170)
- G02에서 넘어온 배합(예 YE:1,OR:3, 300g) → 30방울(1.26g) + 90방울(3.78g)
- 재료를 버터크림으로 바꾸면 재료 안내가 보이고, 생크림이면 안 보이는지
- 음료 800ml · 노랑 → 200방울 · 8.40g · 1,428원, 물 기준 안내 표시
- R01 레몬 에이드 시럽(음료 800ml) → 물 기준 모드로 열림
- R01 마카롱 꼬끄의 [이 양에 색 입히기] → 머랭 370g으로 열리고 안내가 보이는지
