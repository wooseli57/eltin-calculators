# 색·향 계산기 연결 사양 (R01·R02·R03·G01~G05)

상태: 연결 구조 확정 (2026-11-24 채팅, 같은 날 G 분류 개편 반영). 각 계산기의 수치 데이터는 엘틴 자료를 받은 뒤 채움.
R02·R03·G 계산기를 만들 때와 R01의 연결 버튼을 만들 때 이 문서를 함께 따릅니다.

> **2026-11-27 갱신**: G 계산기(G01~G07, 물 바탕 추가)의 계산 방식·데이터·화면은 `docs/specs/G-color.md`를 따릅니다 (K/S 모델 대신 측정표 찾기). 이 문서의 연결 구조와 방울 기준은 그대로 유효합니다.

## 0. 개편 내용 (2026-11-24)

- 엘틴 색소는 모두 **액상**(용량 단위는 g). 액상↔분말 변환은 하지 않음.
- 구 G04 "색소 단위 변환"은 없애고 **방울↔g 변환을 R02에 통합**.
- 향료의 방울·tsp·Tbsp·ml·g 변환은 **R03에 포함**.
- G 분류는 바탕별로 나눔: 식품용(흰 생크림) G01~G03, 놀이용(시판 흰색 클레이) G04~G05.
- 구 G05 "인기 색 레시피"는 따로 두지 않고 G02·G05 안의 **인기 색 버튼**으로 통합.
- 계산기 수는 57개 그대로 (G04·G05 자리에 클레이 계산기).

## 1. 역할 나누기

| 계산기 | 답하는 질문 | 바탕 | 넘기는 곳 |
|---|---|---|---|
| R01 엘틴 레시피 | 무엇을 얼마나 만들까 (색소 없는 표준 레시피, 바닐라 포함) | - | R02(바탕·무게), R03(무게) |
| R02 색소 사용량 | 이 양에 이 색을 내려면 색소가 얼마나 (g·방울·비용) + 방울↔g 변환 | 식품 바탕 전체 | G03 |
| R03 향료 사용량 | 이 양에 향료가 얼마나 + 방울·tsp·Tbsp·ml·g 변환 | - | - |
| G01 혼색 예측 | 색소를 이만큼 섞으면 어떤 색이 될까 | 흰 생크림 | G02 |
| G02 색 배합 | 원하는 색(인기 색 버튼 포함)을 내려면 어떤 조합으로 | 흰 생크림 | R02 |
| G03 농도 조절 | 만든 색을 진하게·연하게 하려면 | 흰 생크림 | - |
| G04 클레이 혼색 예측 | 클레이에 이만큼 섞으면 어떤 색이 될까 | 시판 흰색 클레이 | G05 |
| G05 클레이 색 배합 | 원하는 색(인기 색 버튼 포함)을 클레이로 내려면 | 시판 흰색 클레이 | - (결과에 양까지 표시) |

```
            식품용 (흰 생크림)                                 놀이용 (흰 클레이)
 G01 혼색 예측 ─▶ G02 색 배합 ─(배합)─▶ R02 색소 사용량 ◀─(바탕·g)── R01 레시피     G04 혼색 예측 ─▶ G05 색 배합
                                     │  (g·방울·비용)                │
                 G03 농도 조절 ◀───────┘                              └─(g)──▶ R03 향료 사용량
```

- 식품용 색소 양 계산은 R02가 중심입니다. G02 결과는 R02로 넘겨 내 양·내 바탕에 맞게 계산합니다.
- 놀이용(G04·G05)은 식품 레시피와 연결하지 않고 그 안에서 색소 양까지 보여줍니다 (클레이 g당).
- 계산 방식(K/S 모델)은 생크림과 클레이가 같고 바탕 데이터만 다릅니다. 공통 함수 하나로 만들고 바탕 데이터만 바꿔 씁니다.
- R01은 색소·향료(바닐라 제외) 양을 직접 계산하지 않습니다.

## 2. 방울 기준 (R02·R03 공통)

| 항목 | 값 | 출처 |
|---|---|---|
| 1방울 부피 | **0.04ml** | 사용자 결정 (2026-11-24). 약전 표준 방울 0.05ml보다 작게 잡음 (병 입구·알코올 성분 고려) |
| 엘틴 색소 밀도 | 1.05g/ml | 엘틴 제공 |
| 엘틴 퓨어 바닐라 익스트랙 밀도 | 0.93g/ml | 엘틴 제공 |
| 1tsp / 1Tbsp | 5ml / 15ml | 계량 표준 |

계산 결과 (코드에서는 위 값으로 계산하고, 아래는 확인용):

| | 1방울 | 1g | 1ml | 1tsp | 1Tbsp |
|---|---|---|---|---|---|
| 엘틴 색소 | 0.042g | 약 24방울 | 25방울 · 1.05g | - | - |
| 바닐라 익스트랙 | 0.0372g | 약 27방울 | 25방울 · 0.93g | 125방울 · 4.65g | 375방울 · 13.95g |

- 값은 `data/eltin-colors.json`·`data/eltin-flavors.json`의 `dropMl`(공통 0.04)과 제품별 `density`에 둡니다. 엘틴이 실측하면 이 값만 바꿉니다.
- 방울 수는 정수로 반올림해 표시하고, g은 소수 둘째 자리까지 표시합니다.
- **화면 안내 문구** (R02·R03의 계산 기준과 변환 결과 아래에 항상 표시):
  "1방울은 0.04ml로 계산했어요 (색소 1방울 약 0.042g). 병 입구 모양, 온도, 병을 기울이는 각도, 남은 양에 따라 방울 크기가 달라질 수 있으니 참고용으로 쓰시고, 정확하게 하려면 저울로 g을 재 주세요."
  (R03은 괄호 안을 "바닐라 익스트랙 1방울 약 0.037g"으로)

## 3. 공통 데이터 파일 (한 곳에서만 관리)

| 파일 | 내용 | 쓰는 계산기 |
|---|---|---|
| `data/eltin-colors.json` | `dropMl`, 색소 제품: id, 이름, 색, `density`, 용량(g), 가격, 쓸 수 있는 바탕(`bases`), 권장 사용량(바탕 100g당 g, 농도 단계별), 쇼핑몰 링크 | R02, G01~G05 |
| `data/color-bases.json` | 바탕 종류: id, 이름, 용도(food/play), 바탕색 안내, 보정 배율(기본 1), 주의 문구, Lab 데이터 파일 위치(G용) | R02, R01, G01~G05 |
| `data/color-presets.json` | 인기 색 버튼: id, 색 이름, 표시 색 코드, 바탕(`whipped-cream` 또는 `clay`), 엘틴 배합(제품 id와 바탕 100g당 g, 있으면) | G02, G05, R02 |
| `data/eltin-flavors.json` | `dropMl`, 향료 제품(id, 이름, `density`, 가격, 링크)과 사용 기준. 바닐라 사용 기준(밀가루 125g·우유 250ml당 5ml, 버터 225g당 15ml)도 여기 둠 | R03, R01 |

- 바탕 종류 id: 식품 `whipped-cream`(생크림), `buttercream`, `meringue`, `batter`(반죽), `icing`, `rice`(쌀가루), `drink`(음료), `jelly`, `sugar`, `chocolate` / 놀이 `clay`(시판 흰색 클레이)
- 색 배합과 권장 사용량은 모두 **바탕 100g당**으로 적습니다.
- 초콜릿처럼 물이 들어가면 안 되는 바탕은 `bases`에 없는 제품을 고를 수 없게 합니다.
- 데이터가 아직 없으면 빈 목록으로 두고, 화면에는 "엘틴 데이터 준비 중이에요"를 표시합니다.

## 4. 계산기끼리 값 넘기기 (주소 형식)

| 받는 곳 | 주소 예 | 파라미터 |
|---|---|---|
| R02 | `r02-color-dosage.html?base=buttercream&g=500&color=pastel-pink&level=2` | `base` 바탕 id, `g`(음료는 `ml`), `color` 제품 id 또는 인기 색 id, `level` 1 연하게·2 보통·3 진하게, `from` 보낸 계산기(예: `r01:2`) |
| R03 | `r03-flavor-dosage.html?g=410&flour=100&butter=100&egg=2&from=r01:8` | `g` 또는 `ml`, `flavor`, `from`, 재료 양 `flour`(g)·`milk`(ml)·`butter`(g)·`egg`(개) — R01이 지금 분량 기준으로 넘기면 R03 입력칸을 채움 (2026-11-25 결정) |
| G02 | `g02-color-match.html?c=pastel-pink` | `c` 인기 색 id |
| G05 | `g05-clay-match.html?c=mint&g=100` | `c` 인기 색 id, `g` 클레이 무게 |

- 모든 파라미터는 선택이며, 없거나 잘못되면 기본값으로 엽니다 (오류 없이).
- 블로그 글에서도 같은 주소로 계산기를 바로 열 수 있습니다.
- `from`이 있으면 결과 아래에 "← 레시피로 돌아가기" 링크를 둡니다.
- 받는 계산기가 아직 없으면 보내는 쪽 버튼은 회색 "준비 중". 공통 JS의 확인 목록(예: `Eltin.ready`)을 계산기가 완성될 때 갱신합니다.

## 5. 계산기별 연결 동작

- **R01 → R02·R03**: 레시피의 `color: { step, base, grams }`로 "이 양에 색 입히기" 버튼, `flavor`로 "향 바꾸기" 버튼. 무게는 현재 분량으로 다시 계산한 값.
- **R02 변환 칸**: "다른 레시피에 적힌 양 바꾸기" — 방울 또는 g을 넣으면 반대 단위로. 분말은 다루지 않음.
- **R03 변환 칸**: 방울·tsp·Tbsp·ml·g 중 하나를 넣으면 나머지 단위로 (제품 밀도 사용).
- **G01 → G02**: 혼색 결과에서 "이 색을 기준으로 배합 찾기".
- **G02 → R02**: 인기 색 버튼 또는 목표 색 → 가장 가까운 배합(인기 색 배합 우선, 모델이 준비되면 계산 조합 추가) → "이 배합으로 양 계산" → R02.
- **R02 → G03**: "색이 생각보다 연하거나 진한가요? → 농도 조절" (생크림 바탕일 때).
- **G04 → G05**, **G05**: 클레이 무게를 넣으면 색소 g·방울까지 바로 표시 (방울 기준은 2절과 같음). 놀이용 안전 안내(입에 넣지 않기) 표시.
- **R03 ↔ R01 바닐라**: 같은 `eltin-flavors.json` 기준 사용.
- 색 놀이 레시피(`docs/recipes/color-play.md`: 놀이 반죽, 컬러 슈가)는 블로그 글로 사용.

## 6. 작업 순서

1. R01 완료. 연결 버튼은 R02·R03 완성 전까지 "준비 중".
2. 공통 데이터 파일 4개는 형식만 빈 틀로 두고, `dropMl`·`density`(색소 1.05, 바닐라 0.93)는 지금 채움.
3. R02·R03은 권장 사용량 자료가 오면 사양 작성. 변환 기능은 데이터가 이미 있음.
4. G01·G02·G03(생크림 Lab 데이터), G04·G05(클레이 Lab 데이터) 순서.
