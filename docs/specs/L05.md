# L05 가산수당 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 상시 근로자 수 | 선택 | 5인 이상 | 첫 질문. seg: [5인 이상] [5인 미만]. 도움말: "알바를 포함해 한 달 평균 인원으로 판단해요" |
| 시급(통상시급) | 원 | 해당 연도 최저임금 (2026년 10,320원) | `Eltin.moneyInput()` |
| 연장근로 시간 | 시간 | 0 | 도움말: "하루 8시간 또는 주 40시간을 넘겨 일한 시간" |
| 휴일근로 시간 | 시간 | 0 | 도움말: "쉬는 날에 일한 시간" |
| 야간근로 시간 | 시간 | 0 | 도움말: "밤 10시~아침 6시에 일한 시간 (연장·휴일과 겹쳐도 그대로 넣어주세요)" |

- 시간은 0.5시간 단위.

## 계산식

시급 = w, 연장 = o, 휴일 = h, 야간 = n

- 기본임금(일한 시간분) = w × (o + h)
  - 야간 시간의 기본임금은 정규 근무 또는 연장·휴일 쪽에서 이미 계산되므로 다시 넣지 않음
- **5인 이상** 가산수당
  - 연장 가산 = w × o × 0.5
  - 휴일 가산 = w × min(h, 8) × 0.5 + w × max(h − 8, 0) × 1.0
  - 야간 가산 = w × n × 0.5
  - 휴일 8시간 초과분에 연장 가산을 추가로 얹지 않음
- **5인 미만** 가산수당 = 0
- 추가로 줘야 하는 돈 = 기본임금 + 가산수당 (항목별 원 미만 버림 후 합산)
- 비교: 5인 이상일 때 금액과 5인 미만일 때 금액을 모두 계산

## 결과

- lead: "이번에 추가로 줘야 하는 돈은"
- big: 추가로 줘야 하는 돈
- rows (5인 이상): 연장 기본임금 / 연장 가산(50%) / 휴일 기본임금 / 휴일 가산(8시간까지 50%) / 휴일 가산(8시간 넘는 시간 100%) / 야간 가산(50%) / **합계**(total)
  - 0원인 줄은 숨김
- rows (5인 미만): 연장 기본임금 / 휴일 기본임금 / **합계**(total)
- tip: "5인 이상이면 ○원, 5인 미만이면 ○원이에요."
- tip (5인 미만): "가산수당 의무는 없지만, 일한 시간만큼의 임금은 꼭 지급해야 해요. 근로계약서에 가산수당을 주기로 했다면 그대로 지급해야 해요."

## 계산 기준과 주의 문구

- 가산율: 연장 50%, 야간 50%, 휴일 8시간 이내 50%·8시간 초과 100% (근로기준법 제56조, 상시 5인 이상 사업장 적용)
- 야간 가산은 연장·휴일과 겹치면 각각 더해요
- 공휴일이 원래 일하기로 한 날이면 유급휴일수당이 따로 붙을 수 있어요
- 근로자대표와 서면으로 합의하면 수당 대신 휴가로 줄 수 있어요
- 공통 주의 문구 (CLAUDE.md 6항, 기관: 고용노동부·노무사)

## 결정 메모

- 5인 이상·미만을 첫 질문으로
- 시간대별 시간 직접 입력 (출퇴근 시각 자동 분리는 L04 연결 시 추후)
- 결과에 기본임금과 가산수당을 함께 표시
- 도움말 표현은 "아르바이트" 대신 "알바"
