# A01 최대광고비 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

공통 마진 엔진 `assets/margin-engine.js`(M06 사양 0절)를 사용하고, 결과를 광고 지표 중심으로 보여줍니다.

## 입력

| 항목 | 기본값 | 비고 |
|---|---|---|
| 판매 방식 | 온라인 | seg: [온라인 쇼핑몰] [쿠팡 로켓배송] |
| 판매처 | 방식별 첫 예시 | M06·M07과 같은 목록, 수수료율 예시 채우기 + 직접 수정 + 판매처별 수수료 안내 |
| 판매가 / 매입가 / 마켓수수료율 / 포장비 / 현재 광고비율 / 기타비용 비율 / 소득세율 | M06·M07과 같음 | 소득세율·기타비용 도우미 동일 |

## 결과

- lead: "1개 팔 때 손해 없이 광고에 쓸 수 있는 최대 금액은"
- big: 최대광고비 (= 세후 순이익 + 현재 광고비)
- rows: 최대광고비 비율(판매가 기준) / 최대광고비 비율(납품가 기준, 로켓일 때만) / 현재 광고비 / 현재 세후 순이익 / 최저 목표 광고수익률 / 세금 효과 반영 최대광고비(참고)
- **원형 차트**: 판매가(로켓은 납품가) = 100%로 광고 외 비용 / 현재 광고비 / 남은 광고 여유(세후 순이익). 가운데 글자 "최대광고비 비율 ○%" (`Eltin.donut()`)
- tip: "현재 광고비율이 최대광고비 비율보다 높으면 팔수록 손해예요."
- tip (참고값 설명): "광고비를 늘리면 부가세·소득세도 줄어서 실제로는 조금 더 쓸 수 있어요. 세금 효과 반영값은 그 경우의 참고값이에요."
- 최대광고비가 0 이하이면: "지금 조건으로는 광고비를 쓸 여유가 없어요. 판매가·매입가를 먼저 점검하세요." + 마진계산기(M06/M07) 링크

## 계산 기준과 주의 문구

- 최대광고비 = 세후 순이익 + 현재 광고비, 최대광고비 비율 = 최대광고비 ÷ 판매가
- 로켓배송: 광고비는 납품가 기준으로 계산, 비율은 판매가 기준 대표
- 주의 문구: M06과 같음

## 결정 메모

- 엔진 공유, 온라인/로켓 선택
- 세금 효과 반영값은 참고로 표시
