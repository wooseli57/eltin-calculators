# A03 최저 목표 광고수익률 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력 방식 (seg)

**[간단 계산]** (기본) — 최대광고비를 이미 알 때

| 항목 | 단위 | 비고 |
|---|---|---|
| 판매가 | 원 | 로켓배송은 쿠팡 판매가 |
| 최대광고비 | 원 | 도움말: "모르면 '마진 정보로 계산'을 쓰세요" |

**[마진 정보로 계산]** — A01과 같은 입력 (온라인/로켓, 판매처, 판매가, 매입가, 수수료율(예시+직접 수정+안내), 포장비, 현재 광고비율, 기타비용 비율, 소득세율), 공통 엔진 사용

## 계산

- 최저 목표 광고수익률 = 판매가 ÷ 최대광고비 × 100 (최대광고비 ≤ 0이면 "설정 불가")
- 마진 정보 방식: 엔진의 `minRoas`, 참고값 `minRoasTax`
- 참고: 이 값으로 광고하면 광고비 = 판매가 ÷ (광고수익률 ÷ 100) = 최대광고비

## 결과

- lead: "목표 광고수익률은 최소 이만큼 이상으로 설정하세요"
- big: 최저 목표 광고수익률 (%)
- rows: 판매가 / 최대광고비 / 최대광고비 비율(판매가 기준) / 세금 효과 반영 최저 광고수익률(참고, 마진 정보 방식일 때)
- tip: "이 값보다 낮게 설정하면 광고비가 많이 나가서 팔수록 손해예요. 여유를 두려면 이보다 높게 잡으세요."
- tip (로켓배송): "쿠팡 광고 화면의 광고수익률과 같은 판매가 기준이에요."
- 간단 계산 아래 비교 칸: 같은 판매가에서 최대광고비가 ±20%일 때의 최저 광고수익률

## 계산 기준과 주의 문구

- 광고수익률(ROAS) = 매출 ÷ 광고비 × 100, 판매가 기준
- 주의 문구: M06과 같음

## 결정 메모

- 간단 계산(판매가·최대광고비) + 마진 정보로 계산 두 방식
- 엔진 공유
