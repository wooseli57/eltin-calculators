# L01 인건비 계산기

상태: 확정 (2026-11-23 채팅에서 결정, 2026-11-25 가산수당 개정 — 아래 "2026-11-25 개정" 절이 우선)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 시급 | 원 | 해당 연도 최저임금 (2026년 10,320원) | `Eltin.moneyInput()` |
| 하루 근무시간 | 시간 | 8 | 0.5시간 단위 |
| 주 근무일수 | 일 | 5 | 1~7 칩 버튼 |
| 고용 형태 | 선택 | 4대보험 가입 | seg: [4대보험 가입] [3.3% 프리랜서] |
| 산재보험 요율 | % | 해당 연도 평균 요율 (2026년 1.47%) | 접어두는 "고급 설정" 안에 배치, 업종에 맞게 수정 가능 |

## 계산식

- 주 근무시간 `h` = 하루 근무시간 × 주 근무일수
- 한 달 평균 주 수 `W` = 365 ÷ 7 ÷ 12 = 4.345 (CONFIG.weeksPerMonth)
- 근무시간분 월급 = 시급 × h × W
- 주휴수당: h ≥ 15일 때만
  - 주휴시간 = min(h, 40) ÷ 40 × 8
  - 월 주휴수당 = 시급 × 주휴시간 × W
- 월급 합계(세전) = 근무시간분 월급 + 월 주휴수당
- **4대보험 가입**일 때 사업주 부담 (월급 합계 × 요율, 각 항목 원 미만 버림)
  - 국민연금 = 월급 × 사업주 국민연금 요율
  - 건강보험 = 월급 × 사업주 건강보험 요율
  - 장기요양 = 건강보험료(사업주분) × 장기요양 비율
  - 고용보험 = 월급 × (실업급여 사업주분 + 고용안정·직업능력개발 150인 미만)
  - 산재보험 = 월급 × 산재 요율 (입력값)
  - 사장님 총부담 = 월급 합계 + 위 보험료 합계
  - 직원 실수령액(대략) = 월급 합계 − (국민연금·건강·장기요양·고용보험 근로자분). 소득세·지방소득세는 빼지 않음
- **3.3% 프리랜서**일 때
  - 원천징수 = 월급 합계 × 3.3% (사업소득세 3% + 지방소득세 0.3%), 원 미만 버림
  - 직원 실수령액 = 월급 합계 − 원천징수
  - 사장님 총부담 = 월급 합계 (4대보험 없음)
- 시급 < 해당 연도 최저임금이면 결과 위에 경고

## 결과

- lead: "직원 1명에게 한 달에 드는 돈은"
- big: 사장님 총부담
- rows (4대보험 가입): 근무시간분 급여 / 주휴수당 / 월급 합계(세전) / 사장님 부담 4대보험(합계, 탭하면 5개 항목 펼침) / **사장님 총부담**(total)
- rows (3.3%): 월급 합계 / 원천징수 3.3% / 직원 실수령액 / **사장님 총부담**(total)
- tip: "직원이 실제로 받는 돈은 약 ○원이에요 (소득세 제외)"
- 주 15시간 미만이면 tip에 "주 15시간 미만이라 주휴수당이 없어요"
- 3.3% 선택 시 tip 추가: "출퇴근 시간이 정해져 있고 지시를 받으며 일하면 근로자로 보여 4대보험 가입 의무가 생길 수 있어요."
- 최저임금 미달 경고: "입력한 시급이 ○○년 최저임금(○원)보다 낮아요."

## 계산 기준 (화면 하단, 공통 주의 문구 포함)

- ○○년 기준 요율 표시 (적용 연도 자동)
- 한 달은 평균 4.345주로 계산
- 국민연금·건강보험의 월 소득 상·하한은 반영하지 않아 아주 높거나 낮은 급여는 실제와 다를 수 있어요
- 산재보험은 업종마다 요율이 달라요 (기본값은 전체 평균)
- 공통 주의 문구 (CLAUDE.md 6항)

    2027: {
      minWage: 10700,          // 고용노동부 2027년 적용 최저임금 고시 2026-08-05 (확인 2026-11-23)
      pensionEmployer: 0.05,   // 국민연금 10% (매년 0.5%p 인상 일정, 1월 시행 시 재확인)
      pensionEmployee: 0.05,
      healthEmployer: 0.03595, // 2027년 건강보험료율 7.19% 동결 (보건복지부 2026-09-08)

## 결정 메모

- 월 환산은 4.345주 방식 (월 209시간 고정 방식 사용 안 함)
- 주휴수당은 주 15시간 이상이면 자동 포함
- 산재 기본값은 전체 평균 요율, 사용자가 수정 가능
- 3.3% 프리랜서 선택지 포함 + 근로자성 주의 문구
- 5인 미만·이상 선택은 L01에 넣지 않음 (가산수당은 L05에서 다룸)
- 상시근로자 150인 미만 사업장으로 가정


## 2026-11-25 개정: 사업장 규모와 가산수당 (이 절이 위 내용보다 우선)

### 입력 추가
| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 사업장 규모 | 선택 | 5인 이상 | seg: [5인 이상] [5인 미만]. 근무일수 칩 바로 아래 |

- 주 근무일수는 1~7일 그대로 둠

### 계산 (하루 근무시간 `d`, 주 근무일수 `n`, 시급 `w`)
- 1~6일째(평일·토요일): 근무시간 `hW = d × min(n, 6)`
- 7일째(일주일에 하루 쉬는 날인 주휴일에 일한 것으로 봄): 휴일근무시간 `hH = n === 7 ? d : 0`
- 주 근무시간 합계 `h = hW + hH`
- 기본 급여(주) = w × h (모든 근무시간을 시급으로 한 번)
- **5인 이상**일 때 가산수당(주):
  - 연장근로 가산 = w × 0.5 × max(hW − 40, 0)  (주 40시간 넘는 평일·토요일 근무)
  - 휴일근로 가산 = w × 0.5 × min(hH, 8) + w × 1.0 × max(hH − 8, 0)  (근로기준법 제56조 제2항: 8시간 이내 50%, 넘는 시간 100%)
  - 휴일근로 시간은 연장근로 가산과 겹쳐 계산하지 않음
- **5인 미만**: 가산수당 0 (근로기준법 제56조는 상시 5인 미만 사업장에 적용되지 않음). 근무한 시간만큼 시급은 그대로 지급
- 주휴수당: 주휴시간 = min(hW, 40) ÷ 40 × 8, hW ≥ 15일 때만 (휴일근로 시간은 주휴 계산에 넣지 않음, 사업장 규모와 무관)
- 월 금액 = 주 금액 × W(4.345)
- 월급 합계(세전) = 근무시간분 급여 + 연장근로 가산 + 휴일근로 가산 + 주휴수당 → 4대보험·3.3%는 이 합계로 계산 (기존과 같음)

### 결과 줄
- 근무시간분 급여 / 연장근로 가산 (5인 이상, 0이면 숨김) / 휴일근로 가산 (5인 이상·7일, 0이면 숨김) / 주휴수당 / 월급 합계(세전) / 4대보험 … (기존과 같음)
- 주휴수당 줄 설명: "매주 ○시간분 × 월 평균 4.345주" (예: 매주 8시간분 × 월 평균 4.345주)
- 연장·휴일 가산 줄 설명: "주 ○시간 × 시급의 50%" 형식

### 안내 문구 (tip)
- 5인 이상이고 주 근무시간 합계가 52시간을 넘으면 경고: "주 52시간(기본 40시간 + 연장 12시간)을 넘어요. 5인 이상 사업장은 법정 한도를 넘는 근무를 시킬 수 없어요."
- 7일 근무: "7일째는 주휴일에 일한 것으로 보고 휴일근로로 계산했어요. 주휴일 근무가 계속되지 않도록 쉬는 날을 정해 주세요."
- 5인 미만 선택 시: "5인 미만 사업장은 연장·휴일근로 가산수당이 법적 의무가 아니라 넣지 않았어요. 근로계약서에 정했다면 그대로 지급해야 해요."
- 계산 기준에 추가: "주 40시간 넘는 근무는 연장근로(5인 이상 50% 가산), 7일째 근무는 휴일근로(5인 이상 8시간 이내 50%, 넘는 시간 100% 가산)로 계산해요. 야간근로(밤 10시~오전 6시) 가산은 L05 가산수당 계산기에서 확인하세요."

### 확인용 예시 (2026년, 시급 10,320원, 하루 8시간, 5인 이상)
| 근무일 | 주 근무 | 연장 가산(주) | 휴일 가산(주) | 주휴(주) |
|---|---|---|---|---|
| 5일 | 40h | 0 | 0 | 82,560 |
| 6일 | 48h | 41,280 (8h × 5,160) | 0 | 82,560 |
| 7일 | 56h | 41,280 | 41,280 (8h × 5,160) | 82,560 |
- 7일은 56시간이라 52시간 초과 경고도 나와야 함
