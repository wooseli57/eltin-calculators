# O05 세금 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

화면 맨 위에 탭(seg) 3개: **[부가세] [종합소득세] [법인세]**. 탭마다 입력·결과가 바뀜.

---

## 1. 부가세 탭

### 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 과세 유형 | 선택 | 간이과세자 | seg: [간이과세자] [일반과세자(개인)] [법인] |
| 업종 | 선택 | 카페·음식점·제과점·소매 | 간이과세자일 때만 표시 (아래 표) |
| 매출 | 원 | 비움 | 부가세 포함 금액. 라벨에 기간 표시: 간이 "1년 매출", 일반·법인 "6개월(반기) 매출" |
| 그중 카드·현금영수증 매출 | 원 | 비움 | 개인(간이·일반)일 때만 표시. 신용·체크카드, 현금영수증, 간편결제 포함 |
| 매입 | 원 | 0 | 부가세 포함. 도움말: "세금계산서·카드 등 증빙을 받은 재료비·비품 등" |
| 직전 연도 매출 10억 원 초과 | 체크 | 꺼짐 | 일반과세자(개인)일 때만 표시. 켜면 카드매출 공제 없음 |

간이과세자 업종 선택지 (부가세법 시행령 업종별 부가가치율, 2021.7.1 이후)

| 화면 표시 | 부가가치율 | 예시 (도움말) |
|---|---|---|
| 카페·음식점·제과점·소매 | 15% | 카페, 베이커리, 소품 판매 |
| 직접 만들어 판매 (제조) | 20% | 공예품 제작·판매 |
| 숙박 | 25% | 게스트하우스 |
| 그 밖의 서비스 | 30% | 공방 원데이 클래스, 미용 |
| 전문·임대 서비스 | 40% | 컨설팅, 임대 |

- 업종 아래 안내: "정확한 업종은 사업자등록증의 업종 코드로 확인하세요. 여러 업종을 함께 하면 업종별로 나눠 계산하므로 세무서나 세무사와 상의하세요."

### 계산식 (금액은 원 미만 버림)

**간이과세자 (1년)**
- 납부세액 = 매출 × 부가가치율 × 10%
- 매입 공제 = 매입 × 0.5%
- 카드매출 공제 = min(카드·현금영수증 매출 × 1.3%, 1,000만 원)
- 낼 세금 = max(0, 납부세액 − 매입 공제 − 카드매출 공제) (간이는 환급 없음)
- 매출 < 4,800만 원이면 **납부 면제** (결과 big에 "0원 (납부 면제)", 신고는 해야 한다고 안내)
- 매출 ≥ 1억 400만 원이면 안내: "이 매출이면 다음 해 7월부터 일반과세자로 바뀌어요."

**일반과세자(개인) (반기)**
- 매출세액 = 매출 × 10/110
- 매입세액 = 매입 × 10/110
- 차감 = 매출세액 − 매입세액
- 카드매출 공제 = 10억 초과 체크 시 0, 아니면 min(카드 매출 × 1.3%, 1,000만 원, max(0, 차감)) — 납부세액을 넘을 수 없음
- 낼 세금 = 차감 − 카드매출 공제 (음수면 **환급**)

**법인 (반기)**
- 일반과세자와 같되 카드매출 공제 없음
- 안내: "법인은 3개월마다 예정신고·납부가 있어요."

### 결과

- lead: "이번에 낼 부가세는" / 환급이면 "돌려받을 부가세는" / 면제면 "부가세 납부가 면제돼요"
- big: 낼 세금(또는 환급액)
- rows (간이): 매출 / 업종 부가가치율(○%, 업종 이름) / 납부세액 / 매입 공제 / 카드매출 공제 / **낼 세금**(total)
- rows (일반·법인): 매출 / 매출세액 / 매입세액 / 카드매출 공제(법인은 숨김) / **낼 세금**(total)
- tip: 신고 시기 — 간이 "1년 치를 다음 해 1월 25일까지", 일반 "1~6월분은 7월 25일, 7~12월분은 다음 해 1월 25일까지"

## 2. 종합소득세 탭 (개인사업자, 대략 계산)

### 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 귀속 연도 | 선택 | 올해 | CONFIG에 있는 연도만 |
| 1년 매출 | 원 | 비움 | 부가세 제외 금액 |
| 1년 경비 | 원 | 비움 | 재료비, 인건비, 월세 등 |
| 소득공제 | 원 | 1,500,000 | 도움말: "본인 기본공제 150만 원. 부양가족 1명당 150만 원 추가" |
| 이미 낸 세금 | 원 | 0 | 선택. 중간예납, 3.3% 원천징수 등 |

### 계산식

- 소득금액 = max(0, 1년 매출 − 1년 경비)
- 과세표준 = max(0, 소득금액 − 소득공제)
- 종합소득세 = 과세표준 × 해당 구간 세율 − 누진공제 (원 미만 버림)
- 지방소득세 = 종합소득세 × 10%
- 총 세금 = 종합소득세 + 지방소득세
- 더 낼 세금 = 총 세금 − 이미 낸 세금 (음수면 돌려받을 세금)

### 결과

- lead: "1년 종합소득세는 약"
- big: 총 세금 (지방소득세 포함)
- rows: 소득금액 / 과세표준 / 적용 세율(○% 구간) / 종합소득세 / 지방소득세 / 이미 낸 세금(0이면 숨김) / **더 낼 세금 또는 돌려받을 세금**(total)
- tip: "자녀·노란우산공제 같은 세액공제와 감면은 빠져 있어서 실제로는 더 줄어들 수 있어요. 근로·금융소득 등 다른 소득이 있으면 합쳐서 계산해야 해요."

## 3. 법인세 탭

### 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 사업연도 | 선택 | 올해 | CONFIG에 있는 연도만 (사업연도 개시일 기준 세율) |
| 1년 이익(과세표준) | 원 | 비움 | 도움말: "세무조정을 마친 과세표준 기준이에요. 모르면 대략 이익을 넣어보세요" |
| 성실신고확인 대상 소규모 법인 | 체크 | 꺼짐 | 켜면 최저 구간(2억 이하) 배제 |

### 계산식

- 구간별 누진 계산: 과세표준을 구간별로 나눠 각 세율을 곱해 합산
- 성실신고 소규모 법인 체크 시 2억 원 이하 구간도 다음 구간 세율 적용
- 법인지방소득세 = 법인세 × 10%
- 총 세금 = 법인세 + 법인지방소득세, 실효세율 = 총 세금 ÷ 과세표준

### 결과

- lead: "1년 법인세는 약"
- big: 총 세금 (지방소득세 포함)
- rows: 과세표준 / 구간별 법인세 / 법인지방소득세 / 실효세율 / **총 세금**(total)
- tip: "대표 급여·배당에 대한 소득세는 따로예요. 세액공제·감면은 반영하지 않았어요."

## 계산 기준과 주의 문구 (모든 탭 공통)

- ○○년 기준 (부가세: 간이과세 기준 1억 400만 원·납부면제 4,800만 원, 카드매출 공제 1.3%·연 1,000만 원 / 종합소득세 세율표 / 법인세율)
- 이전 연도 값을 대신 쓰는 항목이 있으면 표시 (CLAUDE.md 6항 규칙)
- 주의 문구:
  > ○○년 기준이에요. 세율, 간이과세 기준, 카드매출 공제율은 세법 개정으로 자주 바뀌어요. 이 계산은 대략적인 예상치이고, 실제 세액은 공제·감면에 따라 달라져요. 정확한 금액은 홈택스나 세무사에게 확인하세요.

## CONFIG (연도별)

```js
const CONFIG = {
  vat: {
    rate: 0.10,
    simplifiedRates: [                 // 간이과세자 업종별 부가가치율 (부가세법 시행령, 2021.7.1 이후)
      { name: "카페·음식점·제과점·소매", rate: 0.15, ex: "카페, 베이커리, 소품 판매" },
      { name: "직접 만들어 판매 (제조)", rate: 0.20, ex: "공예품 제작·판매" },
      { name: "숙박",                     rate: 0.25, ex: "게스트하우스" },
      { name: "그 밖의 서비스",           rate: 0.30, ex: "공방 원데이 클래스, 미용" },
      { name: "전문·임대 서비스",         rate: 0.40, ex: "컨설팅, 임대" }
    ],
    simplifiedPurchaseCredit: 0.005,
    years: {
      2026: {
        simplifiedLimit: 104000000,    // 간이과세 기준 (직전 연도 공급대가, 확인 2026-11-23)
        exemptLimit: 48000000,         // 간이과세자 납부면제 (확인 2026-11-23)
        cardCreditRate: 0.013,         // 신용카드 매출전표 등 발행세액공제, 2026.12.31까지 (확인 2026-11-23)
        cardCreditCap: 10000000,       // 연간 한도
        cardCreditSalesLimit: 1000000000 // 직전 연도 공급가액 10억 초과 개인사업자 제외
      }
      // 2027: 카드매출 공제 1.3%·한도 연장 여부 확인 후 추가 (docs/questions.md)
    }
  },
  incomeTax: {
    years: {
      2026: {                          // 소득세법 제55조, 2023년 개정 세율표 유지 (확인 2026-11-23)
        brackets: [                    // [상한, 세율, 누진공제]
          [14000000, 0.06, 0],
          [50000000, 0.15, 1260000],
          [88000000, 0.24, 5760000],
          [150000000, 0.35, 15440000],
          [300000000, 0.38, 19940000],
          [500000000, 0.40, 25940000],
          [1000000000, 0.42, 35940000],
          [Infinity, 0.45, 65940000]
        ],
        localRate: 0.10
      }
    },
    defaultDeduction: 1500000
  },
  corpTax: {
    years: {
      2025: { brackets: [[200000000,0.09],[20000000000,0.19],[300000000000,0.21],[Infinity,0.24]] }, // 2023~2025 개시 사업연도
      2026: { brackets: [[200000000,0.10],[20000000000,0.20],[300000000000,0.22],[Infinity,0.25]] }  // 법인세법 제55조, 2026.1.1 이후 개시 사업연도 (확인 2026-11-23)
    },
    localRate: 0.10
  }
};
```

- 종합소득세 세율표의 누진공제액은 국세청 세율표로 한 번 더 대조할 것 (구간 경계에서 두 방식 계산값이 같은지 테스트).

## 결정 메모

- 개인사업자 + 법인 모두 포함, 탭 3개
- 간이과세자 업종은 법정 5개 구간 전체를 선택지로 (공예: 제작·판매 20%, 클래스 30%)
- 제과점업은 음식점업 15%
- 세액공제·감면, 추계(단순·기준경비율), 겸업 계산은 제외하고 안내만
- 카드매출 공제 2027년 연장 여부는 확인 필요
