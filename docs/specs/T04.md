# T04 계량 단위 변환

상태: 사양 확정 (2026-11-24 채팅)

## 목적

해외·유튜브 레시피에 컵·큰술·작은술로 적힌 재료를 g으로 바꿔요. 반대로 g을 컵·스푼으로도 바꿔요.
엘틴 향료의 방울·tsp 변환은 R03, 엘틴 색소의 방울↔g 변환은 R02가 맡고, T04는 일반 재료만 다룹니다.

## 입력

1. **재료**: 아래 기준표에서 고르기 (칩 또는 드롭다운, 분류별 묶음: 가루 / 설탕류 / 유제품·지방 / 팽창제·소금 / 기타)
2. **컵 기준**: `미국 레시피 (1컵 236.6ml)` / `한국 레시피 (1컵 200ml)` — 기본값 미국. 숟가락은 미국 1큰술 = 1/16컵(약 14.8ml)·1작은술 = 1/3큰술, 한국 1큰술 15ml·1작은술 5ml
3. **양과 단위**: 숫자 + 단위(컵·큰술·작은술·ml·g). 분수 버튼(1/4·1/3·1/2·2/3·3/4) 제공
4. 입력 4개 이하, 입력 즉시 계산

## 결과

- lead: "밀가루 2컵은 약 240g이에요"
- big: g 값 (반올림: 10g 이상은 정수, 10g 미만은 소수 첫째 자리)
- rows: 같은 양을 컵·큰술·작은술·ml·g으로 모두 표시
- tip: 가루는 "숟가락으로 떠서 컵에 담고 윗면을 깎는 방식 기준이에요. 꾹꾹 눌러 담으면 더 무거워져요" / 흑설탕은 "꾹꾹 눌러 담은 기준"
- 여러 재료를 차례로 바꿔 아래에 쌓는 "목록에 추가" 기능은 넣지 않음 (단순하게 한 재료씩)

## 재료별 기준표 (CONFIG)

## 계산 기준과 주의 문구 (화면)

"재료별 무게는 King Arthur Baking 계량표 기준의 평균값이에요. 가루는 숟가락으로 떠서 컵에 담고 윗면을 깎는 방식 기준이라, 담는 방법·습도·제품에 따라 10% 넘게 달라질 수 있어요. 정확하게 하려면 저울로 재 주세요. 한국 레시피 1컵은 200ml, 미국 레시피 1컵은 약 237ml예요."

## 결정 메모

- 재료 23가지 (카페·베이커리에서 자주 쓰는 재료 위주), 출처는 King Arthur Baking 계량표 하나로 통일
- 컵 기준은 미국(236.6ml)·한국(200ml) 선택, 기본 미국 (해외 레시피 변환이 주 용도)
- 엘틴 향료·색소는 다루지 않음 (R02·R03)
