# E01 온라인쇼핑몰 마진계산기 (+ 공통 마진 엔진)

상태: 확정 (2026-11-23 채팅에서 결정)

기존 "최대비용 마진계산기" PWA 앱(저장소 `wooseli57/margin-calculator`, index.html의 `calcMargin`·`solve`·`progressiveTax`)과 엑셀 `B2최대비용 마진계산기_로켓수정.xlsx`의 계산을 옮깁니다. 로켓배송은 마켓수수료가 납품가에 이미 반영되어 있으므로 비용에 넣지 않습니다.

---

## 0. 공통 마진 엔진 — `assets/margin-engine.js` (E01·E02·A01·A03 공용)

PWA 앱의 계산 함수를 그대로 옮겨 공통 파일로 만듭니다.

```js
// x: { type: 'online'|'rocket', price, buy, fee, pack, ad, etc, tax }  (비율은 % 값)
function calcMargin(x) {
  const E = +x.price || 0, G = +x.buy || 0, J = (+x.fee || 0) / 100, L = +x.pack || 0;
  const M = (+x.ad || 0) / 100, O = (+x.etc || 0) / 100, T = (+x.tax || 0) / 100;
  const rocket = x.type === 'rocket';
  const base = rocket ? E * (1 - J) : E;          // 셀러 관점 판매가 (로켓 = 납품가)
  const feeAmt = E * J;                            // 마켓수수료(원), 로켓은 표시만
  const adAmt = base * M, etcAmt = base * O;
  const pre = base - G - (rocket ? 0 : feeAmt) - L - adAmt - etcAmt;
  const vat = pre > 0 ? pre / 11 : 0;
  const cost = G + (rocket ? 0 : feeAmt) + L + adAmt + etcAmt + vat;   // 로켓은 수수료를 비용에 다시 넣지 않음
  const ebt = base - cost;                         // 세전 순이익
  const tax = ebt > 0 ? ebt * T : 0;
  const net = ebt - tax;                           // 세후 순이익(마진)
  const maxAd = net + adAmt;                       // 최대광고비
  const maxAdTax = pre > 0 ? pre + adAmt : maxAd;  // 세금 효과 반영값 (광고비 증가 시 부가세·소득세 감소 반영)
  return {
    base, feeAmt, adAmt, etcAmt, vat, cost, ebt, tax, net,
    priceMargin: base - G, priceMarginRate: base ? (base - G) / base * 100 : 0,
    netRate: base ? net / base * 100 : 0,
    maxAd,
    maxAdRateSale: E ? maxAd / E * 100 : 0,        // 최대광고비 비율 — 판매가 기준 (쿠팡 광고 화면과 같은 기준)
    maxAdRateBase: base ? maxAd / base * 100 : 0,  // 최대광고비 비율 — 셀러 매출 기준 (온라인은 위와 같음, 로켓은 납품가)
    minRoas: maxAd > 0 ? E / maxAd * 100 : null,   // 최저 목표 광고수익률 (판매가 기준)
    maxAdTax,
    minRoasTax: maxAdTax > 0 ? E / maxAdTax * 100 : null
  };
}
// solve(x, 'buy'|'price', 목표 세후 순이익률%) : 이분법으로 목표 최고 매입가 / 목표 최저 판매가 (PWA 앱 그대로)
// progressiveTax(과세표준원, 세율표) : 누진 세액 (O05 세율표와 공유)
```

- 엔진에는 화면 코드를 넣지 않음. 판매처 목록·수수료 안내 데이터도 이 파일의 `MARGIN_DATA`에 둠 (아래 2·3절).
- 엔진 테스트 (이 채팅에서 PWA 앱 엔진으로 직접 계산한 값):
  - 로켓, 판매가 20,000 · 수수료 35% · 매입가 6,000 · 포장비 200 · 광고 7.69% · 기타 5% · 세율 15% → 세후 순이익 약 3,980원 (엑셀 로켓 상품 1과 같은 입력)
  - 로켓, 판매가 20,000 · 수수료 35% · 포장비 200 · 광고 5% · 기타 5% · 세율 15% · 목표 0% → 목표 최고 매입가 약 11,500원

## 1. 입력 (E01 온라인)

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 판매처 | 선택 | 스마트스토어 · 네이버 유입 · 영세 | 고르면 마켓수수료율이 **예시값으로 채워짐**. 마지막 선택지 "직접 입력" |
| 판매가 | 원 | 비움 | 소비자가 내는 가격 (부가세 포함) |
| 매입가 / 제조원가 | 원 | 비움 | 부가세 포함 |
| 마켓수수료율 | % | 판매처 예시값 | **언제든 직접 수정 가능**. 바로 아래 "판매처별 수수료 안내" 링크(접는 칸) |
| 포장비 | 원 | 200 | |
| 광고비율 | % | 5 | 판매가 대비 |
| 기타비용 비율 | % | 5 | 도우미: 월 고정비 ÷ 월 예상 매출 × 100 → [이 비율 쓰기] |
| 소득세율 | % | 15 | 도우미: [개인] [법인] + 예상 연간 과세표준 + 지방소득세 포함 체크 → 실효세율 → [이 세율 쓰기] |

- 판매처를 고른 뒤 수수료율을 고치면 판매처 표시 옆에 "(직접 수정)" 표시.

## 4. 결과

- lead: "1개 팔면 세금까지 빼고 남는 돈은"
- big: 세후 순이익 (+ 세후 순이익률 %)
- rows: 판매가 / 가격마진(율) / 마켓수수료 / 포장비 / 광고비 / 기타비용 / 부가세 / 소득세 / **세후 순이익**(total)
- **비용 구조 원형 차트** (rows 위): 판매가 = 100%로 매입가 / 마켓수수료 / 포장비 / 광고비 / 기타비용 / 부가세 / 소득세 / 세후 순이익 비율. 가운데 글자 "세후 순이익률 ○%". 공통 기능 `Eltin.donut()` 사용 (CLAUDE.md 4항)
- 손실이면 big을 빨간 계열이 아닌 테마 진한색 + "손실" 표시, tip: "판매가를 올리거나 매입가를 낮춰야 해요. 아래 목표 설계를 써보세요."
- tip (광고 지표): "최대광고비 ○원(판매가의 ○%) · 최저 목표 광고수익률 ○%"
- **목표 설계** (접는 칸): 목표 세후 순이익률(기본 0% = 손익분기) 입력 → "목표 최고 매입가 ○원 / 목표 최저 판매가 ○원"

## 5. 계산 기준과 주의 문구

- 계산 순서 요약: 비용(매입가·수수료·포장비·광고비·기타비용) → 부가세 = (판매가 − 비용) ÷ 11 → 세전 순이익 → 소득세 → 세후 순이익
- 주의 문구:
  > ○○년 기준이에요. 판매처 수수료는 카테고리·프로모션·판매처 정책에 따라 바뀌고, 세율은 세법 개정으로 달라질 수 있어요. 기본값은 예시이니 내 상품의 실제 값으로 바꿔 넣으세요. 참고용으로 사용하시고, 정확한 금액은 판매자센터와 세무사에게 확인하세요.

## 결정 메모

- PWA 앱 계산 엔진을 공통 파일로 이식
- 판매처 선택은 예시값 채우기용, 수수료율은 항상 직접 수정 가능 + 판매처별 수수료 안내 표
- 소득세율·기타비용 비율은 직접 입력 + 도우미
- 결과에 비용 구조 원형 차트 표시 (PWA 앱의 원형 차트와 같은 구성)
- 목표 설계 포함, 저장·비교 기능 제외 (값 저장하지 않는 원칙)
