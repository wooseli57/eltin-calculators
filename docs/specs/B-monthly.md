# 월 마진 연결 계산 B01~B08 사양

상태: 사양 확정 (2026-11-25 채팅). 원칙과 근거: `docs/restructure-2026-11.md` 2·3절.
만드는 순서 추천: **B07 월 손익 → B05 월 운영비 → B04 월 인건비 → B01 월 원가 → B02 월 판매비 → B03 월 광고비 → B06 월 매출 → B08 투자회수**
(B07만 있어도 모든 비용을 직접 넣어 쓸 수 있으므로 가장 먼저)

## 0. 공통

### 매장·온라인 탭
- 8개 모두 맨 위에 seg `[매장] [온라인]`. 탭은 계산식이 아니라 **예시 문구·기본값·항목 이름**만 바꿈
- 주소 `?m=store|online`으로 시작 탭 지정 (기본 store). 탭을 바꾸면 다음 단계 링크에도 `m` 유지

### 비용 분류와 고정·변동
| 비용 | 키 | 구분 |
|---|---|---|
| ① 원가 | `mat` | 변동 |
| ② 판매비 | `sell` | 변동 |
| ③ 광고비 | `ad` (+ `adv=1`이면 변동) | 기본: 매장 고정, 온라인 변동 |
| ④ 인건비 | `labor` | 고정 |
| ⑤ 운영비 | `opex` (그중 감가상각 `dep`) | 고정 |
- 매출 `sales`

### 값 넘기기 (저장 없이 주소로)
- 각 단계 결과 아래 "다음 단계 →" 버튼: 지금까지 받은 파라미터 + 이 단계 결과를 붙여 다음 계산기로 (예: B01 → `b02-monthly-selling.html?m=store&sales=15000000&mat=4500000`)
- 모든 단계에 "월 손익으로 바로 가기 →" 버튼도 둠 (중간 단계 건너뛰기)
- 받은 값이 있는 계산기는 입력칸을 그 값으로 채우고 "앞 단계에서 가져온 값이에요" 표시. 사용자가 고칠 수 있음
- 금액은 원 단위 정수로 넘김. 잘못된 값은 무시하고 기본값

### 공통 결과·문구
- 금액 입력은 `Eltin.moneyInput()`, % 입력은 소수 1자리까지
- 각 비용 단계 결과: 그 비용 합계 + "매출의 ○%" (매출을 알 때) + 항목별 원그래프
- 계산 기준 공통 문구: "한 달 평균 기준이에요. 매출과 비용은 같은 기준(둘 다 부가세 포함 또는 둘 다 제외)으로 넣어 주세요."

## B07 월 손익 계산기 (중심, 손익 7/8)

### 입력
1. 탭 [매장]/[온라인]
2. **월 매출** (`sales`): 금액. 기본 매장 15,000,000 / 온라인 10,000,000. 옆에 "자세히 계산 →" (B06)
3. **비용 5줄**: 줄마다 입력 방식 seg `[금액] [매출의 %]`, 앞 단계에서 받은 값이 있으면 seg 맨 앞에 `[가져온 값]`이 생기고 선택됨
   | 줄 | 기본값 (매장) | 기본값 (온라인) | 자세히 계산 |
   |---|---|---|---|
   | 원가 | 매출의 30% | 매출의 40% | B01 |
   | 판매비 | 매출의 5% | 매출의 15% | B02 |
   | 광고비 | 300,000원 | 매출의 10% | B03 |
   | 인건비 | 4,000,000원 | 0원 | B04 |
   | 운영비 | 3,000,000원 (그중 감가상각 500,000원) | 500,000원 (감가상각 0) | B05 |
   - 운영비 줄 아래 작은 칸 "그중 시설 감가상각" (금액, 기본 위 표). B05에서 오면 `dep`로 채움
   - 광고비 줄 옆 작은 체크 "매출에 따라 늘어나는 광고" (기본: 매장 꺼짐, 온라인 켜짐. % 모드로 넣으면 자동으로 켜짐)
4. 고급(접는 칸): "온라인 월 이익 더하기" (매장 탭에서만, 금액. 매장과 온라인을 같이 하는 사장님용. 결과의 한 달 이익에 더함)

### 계산
- 각 비용 = 금액 또는 `sales × %`
- 변동비 = 원가 + 판매비 + (광고비가 변동이면 광고비)
- 고정비 = 인건비 + 운영비 + (광고비가 고정이면 광고비)
- **감가상각 후 이익** = 매출 − 변동비 − 고정비 (+ 온라인 월 이익)
- **감가상각 전 이익** = 감가상각 후 이익 + 감가상각
- 이익률 = 감가상각 후 이익 ÷ 매출
- 변동비율 = 변동비 ÷ 매출
- **손익분기 매출** = 고정비 ÷ (1 − 변동비율) (변동비율 ≥ 100%면 "팔수록 손해예요" 경고, 손익분기 없음)
- **1년 환산** = 감가상각 후 이익 × 12

### 결과
- lead: "한 달에 남는 돈은" (적자면 "한 달에 ○원 적자예요")
- big: 감가상각 후 이익
- 원그래프: 원가·판매비·광고비·인건비·운영비·이익(이익이 양수일 때 마지막, `profitLast: true`), 가운데 "이익률 ○%"
- rows: 월 매출 / 원가 / 판매비 / 광고비 / 인건비 / 운영비 / **한 달 이익 (감가상각 후)** / 통장에 남는 돈 (감가상각 전) / 손익분기 매출 / 1년이면 약
- tip:
  - "매출이 ○원(손익분기 매출)보다 적으면 적자예요. 지금은 손익분기보다 ○% 많이 팔고 있어요." (또는 부족)
  - "사장님 본인 인건비를 넣지 않았다면, 남는 돈이 곧 사장님 몫이에요." (인건비 줄에 사장님 급여 포함 여부는 B04 안내와 같은 문구)
- 버튼 줄: [1년 이익으로 세금 계산 →] (O05 세금 계산기로 연간 이익 전달, 파라미터는 O05에 맞춰 추가: 예 `income=` 연간 감가상각 후 이익) / [투자회수 계산 →] (B08로 `profit=` 감가상각 전 이익, 고정비 `fixed=`, 변동비율 `vr=`)
- [결과 복사] [처음으로]

### 계산 기준
- 공통 문구 + "시설비는 사용 기간으로 나눈 감가상각비로 넣어요. 통장에 남는 돈은 감가상각을 빼기 전 금액이에요."
- "1년 환산은 한 달 이익 × 12예요. 성수기·비수기가 있으면 평균 월 매출로 넣으세요."
- "세금(부가세·소득세)은 빼기 전 금액이에요. 세금은 세금 계산기에서 1년 이익으로 확인하세요."

## B01 월 원가 계산기 (비용 1/8)
- 기존 `docs/specs/B01.md`(옛 C06.md)를 이 절로 대체
- 입력: 월 매출(선택, %·원가율 계산용) / 입력 방식 seg `[품목별] [매출의 %]`
  - 품목별: `rowList` (품목 이름, 월 구입액). 매장 기본 줄: 원재료, 자재(컵·박스) / 온라인: 상품 매입·제조, 포장재
  - 매출의 %: 매장 30% / 온라인 40%
  - 폐기·손실(참고) %: 기본 3%, 합계에 더하지 않음
- 결과: 월 원가 합계, 원가율, 품목별 원그래프, 폐기 참고 tip ("구입한 원료 중 약 ○원어치가 버려지고 있어요. 폐기를 1%p 줄이면 한 달 약 ○원")
- 다음 단계: B02 (`mat`, `sales`)
- 계산 기준: 한 달 구입액 기준, 재고가 크게 변하지 않는 달 기준, 폐기는 이미 구입액에 포함

## B02 월 판매비 계산기 (비용 2/8)
- 입력 방식 seg `[항목별] [매출의 %]` (% 기본: 매장 5% / 온라인 15%)
- 항목별 (월 매출이 있으면 매출 비율 칸 사용):
  - 매장: 카드수수료 = 카드 매출 비율(기본 90%) × 매출 × 수수료율(기본 1.0%, "내 수수료율 확인 →" O02) / 배달앱 수수료 = 배달 매출 비율(기본 0%) × 매출 × (중개 7.8% + 결제 3%, S03과 같은 예시값) / 배달비 = 배달 건수 × 건당 배달비(기본 0)
  - 온라인: 마켓 수수료 = 매출 × 수수료율(기본 10.8%, 마켓 예시 칩은 E01 사양 0절 프리셋 재사용) / 택배·물류비 = 발송 건수 × 건당 비용(기본 3,000원) / 결제수수료(선택)
- 결과: 월 판매비, 매출 대비 %, 항목별 원그래프
- 다음 단계: B03 (`sell` 추가)
- 주의 문구: 수수료율은 예시값이며 매출 규모·계약·정책에 따라 달라요 (S03·O02 문구 재사용)

## B03 월 광고비 계산기 (비용 3/8)
- `rowList`: 광고 이름, 방식 seg `[월 금액] [매출의 %]`, 값
  - 매장 기본 줄: 지역광고(월 금액 200,000), 체험단·쿠폰(월 금액 100,000)
  - 온라인 기본 줄: 마켓 광고(매출의 8%), SNS 광고(월 금액 200,000)
- % 줄이 하나라도 있으면 그 줄은 변동비, 금액 줄은 고정비로 나눠 합계 표시
- 결과: 월 광고비 합계 (고정 ○원 + 매출 비례 ○원), 매출 대비 %, 1회성 광고 계산기 링크(A01~A06)
- 다음 단계: B04 (`ad`, `adv`: 매출 비례분이 더 크면 1. 고정·변동 금액을 나눠 넘기려면 `adf`·`adv` 두 키로 넘겨도 됨, B07에서 합쳐 처리)

## B04 월 인건비 계산기 (비용 4/8)
- 입력 방식 seg `[직원별] [전체 금액]`
- 직원별 `rowList`: 이름, 방식 seg `[시급] [월급]`
  - 시급: 시급(기본 해당 연도 최저임금), 하루 시간, 주 일수 → **L01과 같은 계산식**(주휴수당, 사업장 규모별 연장·휴일 가산 포함. 사업장 규모는 화면 위 공통 seg 하나)
  - 월급: 월 급여(세전)
  - 4대보험: 공통 seg `[4대보험 가입] [3.3%]` 기본 가입, 줄마다 바꿀 수 있게 (가입이면 L01 사업주 부담분 더함, 3.3%는 원천징수만 하고 사장님 부담 추가 없음)
- 전체 금액: 4대보험 포함 월 인건비 총액 1칸
- "사장님 본인 급여도 넣을까요?" 체크(기본 꺼짐) + 금액. 안내: "넣으면 남는 돈이 순수한 가게 이익, 안 넣으면 남는 돈이 사장님 몫이에요"
- 결과: 월 인건비 합계(급여 + 사장님 부담 4대보험), 직원별 rows, 원그래프, 매출 대비 %(매출을 알 때)
- 다음 단계: B05 (`labor`)
- CONFIG 연도별 요율은 L01과 같은 값을 써야 하므로 L01의 CONFIG를 공통 파일로 옮기거나 같은 값을 복사하고 주석으로 L01 기준임을 표시
- L01 결과의 "월 인건비에 넣기" 버튼: `b04-monthly-labor.html?add=<이 직원 월 부담액>` → B04에서 한 줄로 추가

## B05 월 운영비 계산기 (비용 5/8, 옛 B05 개편)
- `rowList` (항목, 월 금액). 기본 줄
  - 매장: 월세, 관리비, 공과금(전기·가스·수도), 통신·POS, 보험, 세무기장료
  - 온라인: 창고·사무실, 쇼핑몰 솔루션·프로그램, 공과금, 통신, 세무기장료
- **시설 감가상각** 칸 (줄과 별도 묶음): 시설비(인테리어·장비, 기본 매장 30,000,000 / 온라인 0), 사용 기간(년, 기본 5), 이미 쓴 기간(년, 기본 0)
  - 월 감가상각 = 이미 쓴 기간 < 사용 기간이면 시설비 ÷ (사용 기간 × 12), 아니면 0
  - 0이면 tip: "사용 기간이 지난 시설이에요. 장비 교체에 대비해 매달 ○원(시설비 ÷ 사용 기간 ÷ 12)씩 모아 두면 좋아요."
  - "자세히 계산 →" O01
- **기타 (잘 모르는 비용 전부)**: seg `[금액] [매출의 %]`, 기본 매출의 3% (매출을 모르면 금액 200,000). 안내: "생각나지 않는 비용을 한 번에 넣어 두면 이익을 부풀려 보는 걸 막을 수 있어요"
- 결과: 월 운영비 합계(감가상각 포함), 그중 감가상각, 항목별 원그래프
- 다음 단계: B06 (`opex`, `dep`)

## B06 월 매출 계산기 (매출 6/8, 옛 B06 개편)
- seg `[예상 매출] [목표 매출]`
- 예상 매출
  - 매장: 객단가(기본 7,000원) × 하루 손님(기본 80명) × 월 영업일(기본 26일) + 배달 매출(선택, 월 금액)
  - 온라인: `rowList` (상품 이름, 판매가, 월 판매량) 또는 월 매출 총액
- 목표 매출: 목표 월 이익(기본 3,000,000원) → **필요한 매출 = (목표 이익 + 고정비) ÷ (1 − 변동비율)**
  - 고정비·변동비율은 앞 단계 값(`labor`·`opex`·`ad`·`mat`·`sell`·`sales`)이 있으면 계산해서 채우고, 없으면 직접 입력 칸 (고정비 기본 7,300,000원, 변동비율 기본 35%)
  - 매장이면 "하루 손님 ○명(객단가 ○원 기준)", 온라인이면 "상품 평균 판매가 기준 하루 ○개"로 환산
- 결과: 월 매출 / 하루 매출, (목표 모드) 지금 매출과의 차이
- 다음 단계: B07 (`sales`)

## B08 투자회수 계산기 (손익 8/8, 옛 B08 개편)
- 입력: 초기 투자금(시설비·권리금·초기 재고 등, 기본 50,000,000원. 안내: "임대 보증금은 나중에 돌려받는 돈이라 빼고 넣으세요") / 월 이익 — **감가상각 전** (B07에서 `profit`으로 받음, 기본 3,000,000원)
- 결과: 회수 기간 = 초기 투자금 ÷ 월 이익 (개월, ○년 ○개월), 회수 완료 예상 연월
- 목표 기간 (접는 칸): 목표 개월(기본 24) → 그 안에 회수하려면 필요한 월 이익 = 투자금 ÷ 목표 개월, 필요한 월 매출 = (고정비 + 투자금 ÷ 목표 개월) ÷ (1 − 변동비율) (고정비·변동비율은 `fixed`·`vr`로 받거나 직접 입력)
- 계산 기준: "월 이익은 감가상각을 빼기 전 금액으로 넣어요. 시설비가 이미 투자금에 들어 있어서 감가상각까지 빼면 두 번 빼는 셈이에요."
- 기존 B08 화면의 입력·결과는 유지하고 위 내용을 추가

## 확인용 예시 (B07, 매장 기본값)
- 매출 15,000,000 / 원가 30% 4,500,000 / 판매비 5% 750,000 / 광고비 300,000(고정) / 인건비 4,000,000 / 운영비 3,000,000(감가상각 500,000)
- 변동비 5,250,000 (35%), 고정비 7,300,000
- 감가상각 후 이익 2,450,000 (16.3%), 감가상각 전 2,950,000
- 손익분기 매출 = 7,300,000 ÷ 0.65 = 11,230,769 → 11,230,769원
- 1년 환산 29,400,000
- 온라인 기본값: 매출 10,000,000 / 원가 4,000,000 / 판매비 1,500,000 / 광고비 1,000,000(변동) / 인건비 0 / 운영비 500,000 → 이익 3,000,000, 변동비율 65%, 고정비 500,000, 손익분기 1,428,571원
