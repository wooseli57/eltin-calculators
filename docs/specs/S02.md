# S02 배달 판매가 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 매장 판매가 | 원 | 비움 | 부가세 포함 가격 |
| 메뉴 1개 원가 | 원 | 비움 | 재료비 + 포장비 |
| 중개수수료율 | % | 7.8 | 예시값, C03과 동일한 입력 방식 |
| 결제수수료율 | % | 3.0 | 예시값 |
| 사장님 부담 배달비 | 원 | 비움 | 1건당 |
| 한 주문당 평균 메뉴 개수 | 개 | 1 | 배달비를 메뉴 수로 나눔 |
| 수수료에 부가세 포함 | 체크 | 켜짐 | |
| 가격 끝자리 | 선택 | 100원 단위 | seg: [100원 단위] [500원 단위] [그대로], 올림 |

## 계산식

- vat = 체크 시 1.1, 아니면 1.0
- f = (중개수수료율 + 결제수수료율) ÷ 100 × vat
- 메뉴 1개당 배달비 d = 사장님 부담 배달비 ÷ 평균 메뉴 개수
- 매장에서 남는 돈 P = 매장 판매가 ÷ 1.1 − 원가
- 배달 판매가(올림 전) x = (P + 원가 + d) ÷ (1 ÷ 1.1 − f)
  - 분모가 0 이하이면 "수수료율이 너무 높아 계산할 수 없어요" 표시
- 배달 판매가 = x를 가격 끝자리 단위로 올림
- 검산: 배달에서 남는 돈 = 배달 판매가 ÷ 1.1 − 원가 − 배달 판매가 × f − d (≥ P 이어야 함)
- 인상 금액 = 배달 판매가 − 매장 판매가, 인상률 = 인상 금액 ÷ 매장 판매가 × 100

## 결과

- lead: "배달앱에서는 이 가격에 팔아야 매장만큼 남아요"
- big: 배달 판매가
- rows: 매장 판매가 / 매장에서 1개 남는 돈 / 배달 수수료(1개) / 메뉴 1개당 배달비 / 배달에서 1개 남는 돈 / **매장가보다 ○원(○%) 높게**(total)
- tip: "배달팁(손님이 내는 배달비)을 받으면 그만큼 사장님 부담이 줄어요."
- compare (선택): 같은 원가율을 지키려면 필요한 가격을 참고로 한 칸 표시 — "원가율까지 매장과 같게 하려면 ○원"

## 계산 기준과 주의 문구

- 매장과 배달에서 메뉴 1개당 남는 금액을 같게 맞춘 가격
- 판매가는 부가세 포함, 끝자리는 올림
- 배달팁, 광고비, 쿠폰·할인 부담분은 반영하지 않음
- 주의 문구 (C03과 동일):
  > 기본값은 예시예요. 배달앱 수수료와 배달비는 앱마다 다르고, 가게의 매출 구간, 가게와 손님 사이의 거리, 앱의 정책에 따라 수시로 바뀌어요. 참고용으로 사용하시고, 정확한 금액은 각 앱의 정산서와 공지를 확인하세요.

## 결정 메모

- 기준은 "남는 금액 같게" (원가율 같게는 참고 표시만)
- 배달팁은 계산에서 제외, 안내만
- 끝자리 처리는 S01과 동일
