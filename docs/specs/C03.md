# C03 배달비용 계산기

상태: 확정 (2026-11-23 채팅에서 결정)

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 주문 금액 | 원 | 비움 | 손님이 결제한 음식값 (배달팁 제외), `Eltin.moneyInput()` |
| 중개수수료율 | % | 7.8 | 예시값. 칩: 2.0 / 6.8 / 7.8 + 직접 입력 |
| 결제수수료율 | % | 3.0 | 예시값, 직접 입력 |
| 사장님 부담 배달비 | 원 | 비움 | 정산서의 1건당 배달비(사장님 부담분) 직접 입력 |
| 수수료에 부가세 포함 | 체크 | 켜짐 | 켜면 중개·결제수수료에 × 1.1 |

- 앱 이름(배민·쿠팡이츠·요기요 등)은 화면에 쓰지 않음.
- 입력칸 아래 안내: "예시값이에요. 내 가게 정산서의 실제 요율과 배달비로 바꿔주세요."

## 계산식

- vat = 체크 시 1.1, 아니면 1.0
- 중개수수료 = 주문 금액 × 중개수수료율 × vat (원 미만 버림)
- 결제수수료 = 주문 금액 × 결제수수료율 × vat (원 미만 버림)
- 배달 1건 총비용 = 중개수수료 + 결제수수료 + 사장님 부담 배달비
- 비용 비율 = 총비용 ÷ 주문 금액 × 100
- 정산받는 금액 = 주문 금액 − 총비용

## 결과

- lead: "배달 1건에 사장님이 내는 돈은"
- big: 배달 1건 총비용
- rows: 중개수수료 / 결제수수료 / 사장님 부담 배달비 / 주문 금액 대비 비율(%) / **정산받는 금액**(total)
- tip: "광고비, 쿠폰·할인 부담분은 빠진 금액이에요. 매장 판매가와 비교하려면 배달 판매가 계산기(S02)를 써보세요."

## 계산 기준과 주의 문구

- 수수료는 주문 금액(음식값) 기준, 부가세 포함 여부는 선택
- 거리별·주문금액별 배달비 구간은 반영하지 않고 1건당 금액으로 계산
- 주의 문구:
  > 기본값은 예시예요. 배달앱 수수료와 배달비는 앱마다 다르고, 가게의 매출 구간, 가게와 손님 사이의 거리, 앱의 정책에 따라 수시로 바뀌어요. 참고용으로 사용하시고, 정확한 금액은 각 앱의 정산서와 공지를 확인하세요.

## CONFIG

```js
const CONFIG = {
  baseYear: 2026,
  defaults: {
    brokerRate: 7.8,   // 예시: 주요 배달앱 차등 수수료의 최고 구간 (부가세 별도). 쿠팡이츠 상생요금제 7.8%/6.8%/2.0% 보도 참고 (확인 2026-11-23)
    payRate: 3.0,      // 예시: 배민 결제수수료 3% 보도 참고 (확인 2026-11-23)
    brokerChips: [2.0, 6.8, 7.8]
  },
  vat: 1.1
};
```

## 결정 메모

- 앱별 요율 고정 대신 직접 입력 + 예시 기본값
- 1건당 고정 배달비로 단순화
- 수수료 부가세 포함 기본 켜짐
- 광고비·할인 부담분은 제외하고 안내만
