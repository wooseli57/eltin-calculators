# R01 엘틴 레시피 계산기

상태: 사양 확정 (2026-11-24 개정). 색소 없는 표준 레시피로 바꿔서 R02 데이터 없이 지금 만들 수 있음.
연결 방식은 `docs/specs/color-flavor-links.md`를 함께 따름.

## 데이터

- 원본: `docs/recipes/eltin-recipes.md` (레시피 20개, 사람이 읽고 고치는 문서)
- 코드에서 쓰는 형태: `data/eltin-recipes.json`으로 변환 (Claude Code가 원본 문서를 읽어 생성. 원본을 고치면 JSON도 다시 생성)
  - 레시피 하나: `{ id, name, audience, base: { mode: 'count'|'pan'|'weight'|'volume', amount, unit, pan? }, ingredients: [{ name, amount, unit, note, countUnit?, eltin?: 'vanilla' | 'vanilla-oil' }], color?: { step, base, grams, note? }, flavor?: { step, label, grams }, steps: [...], tips: [...], cautions: [...], source? }`
  - `color`: 레시피 문서의 `색을 넣으려면` 줄. `base`는 `data/color-bases.json`의 바탕 id (생크림 `whipped-cream`, 버터크림 `buttercream` 등)
  - `flavor`: 레시피 문서의 `향을 바꾸려면` 줄
  - 범위 값(30~45ml, 1~2샷)은 `amount: [30, 45]`로 저장하고 배수를 양쪽에 모두 적용
- 바닐라 양은 레시피에 적힌 값을 그대로 쓰고 배수만 적용 (기준은 `data/eltin-flavors.json`과 같음)

## 화면

1. **레시피 고르기**: 상단에 레시피 카드 목록(가로 스크롤 칩 또는 드롭다운). 주소 `r01-eltin-recipe.html?r=<id>`로 특정 레시피를 바로 열 수 있음 (블로그 글마다 연결)
2. **양 정하기**: R04와 같은 엔진, 레시피의 `base.mode`에 맞는 입력을 기본으로 보여줌
   - 개수: "몇 개 만들까요?" (기본 = 레시피 기본 분량)
   - 틀: R07 크기표 호수 칩 (기본 1호)
   - 무게·부피: "몇 g(ml) 만들까요?"
   - 공통: 배수 버튼(0.5배·1.5배·2배), 기준 재료("버터가 ○g밖에 없어요")
3. **재료 표**: 재료 / 계산된 양 / 메모. 개수 재료(달걀)는 "2.5개 → 3개 (약 150g)"처럼 표시. 엘틴 제품 줄(바닐라)은 테마색 표시 + 쇼핑몰 상품 링크(있을 때)
4. **색·향 안내** (재료 표 아래, 해당 레시피만):
   - `color`가 있으면: "원하는 색을 내려면 ○단계에서 ○○에 넣어요. 색 입힐 양: 약 ○g" + **[이 양에 색 입히기]** → R02 (`base`, `g`=현재 분량으로 다시 계산한 무게, `from=r01:<id>`)
   - `flavor`가 있으면: "다른 향으로 바꾸려면 ○단계에서 넣어요" + **[향 바꾸기]** → R03
   - R02·R03이 아직 없으면 버튼은 회색 "준비 중"
5. **만드는 법·팁·주의**: 접는 칸
6. **내 레시피로 가져가기**: 현재 재료와 양을 R04 화면으로 넘김 (주소 파라미터 또는 sessionStorage, 실패해도 동작에 문제 없게)
7. 결과 lead 예시: "마카롱 꼬끄 45개를 만들려면" / big: 배수 "1.5배"

## 계산 기준과 주의 문구

- 기본 분량은 엘틴 테스트 기준이며, 오븐·재료 상태에 따라 굽는 시간과 수율이 달라질 수 있어요
- 바닐라는 달걀·유제품의 잡내를 잡기 위한 표준 양이에요. 오븐에 굽는 레시피는 엘틴 바닐라오일(달걀 1개당 ½ tsp), 굽지 않는 레시피는 엘틴 퓨어 바닐라 익스트랙(밀가루 125g·우유 250ml당 1tsp, 버터 225g당 3tsp) 기준이에요
- 색을 입히면 바탕색에 따라 색이 달라질 수 있어요 (버터크림은 노란빛)

## 결정 메모

- 레시피 20개. 색소는 넣지 않고, 색이 필요하면 R02로 안내 (2026-11-24 개정)
- 바닐라는 달걀·유제품 레시피에 표준 양 포함. 레몬·과일 향은 넣지 않고 R03으로 안내
- 레인보우 컵케이크 → 바닐라 컵케이크(레인보우는 팁으로), 2색 아이스박스 쿠키 → 바닐라·코코아 2색 쿠키
- 아이 놀이 반죽·컬러 슈가는 색 놀이용이라 `docs/recipes/color-play.md`로 옮기고, 휘낭시에·스콘 추가
- 바닐라 시럽·라떼는 엘틴 상세페이지 레시피 그대로
- 레시피 초안은 엘틴 실제 테스트 후 확정하고 공개

## 2026-11-25 개정
- 오븐에 굽는 레시피 10개(마카롱·제누아즈·아이싱 쿠키·컵케이크·마들렌·휘낭시에·머랭쿠키·파운드·2색 쿠키·스콘)는 **엘틴 바닐라오일 클래식**, 굽지 않는 레시피는 **엘틴 퓨어 바닐라 익스트랙**. 양은 `docs/recipes/eltin-recipes.md` 그대로 (오일은 달걀 1개당 2.5ml)

- 바닐라 에센스 대체 문구는 뺌 (시럽·라떼·생크림·아이스크림)
