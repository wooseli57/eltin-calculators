# M07 로켓배송 마진계산기

상태: 확정 (2026-11-23 채팅에서 결정)

공통 마진 엔진 `assets/margin-engine.js`(M06 사양 0절)를 `type: 'rocket'`으로 사용합니다. 마켓수수료는 납품가에 이미 빠져 있으므로 비용에 넣지 않습니다.

## 입력

| 항목 | 단위 | 기본값 | 비고 |
|---|---|---|---|
| 판매처 | 선택 | 쿠팡 로켓배송 | 선택지: 쿠팡 로켓배송(35% 예시) / 직접 입력 |
| 쿠팡 판매가 | 원 | 비움 | 소비자가 쿠팡에서 내는 가격 |
| 매입가 / 제조원가 | 원 | 비움 | |
| 마켓수수료율(공급률 차이) | % | 35 | **직접 수정 가능**. 도움말: "쿠팡과 협상한 공급률에 따라 다르며 보통 판매가의 약 35~40%" + 판매처별 수수료 안내(M06과 같은 표) |
| 포장비 | 원 | 200 | |
| 광고비율 | % | 7.69 | 도움말: "납품가 대비" |
| 기타비용 비율 | % | 5 | 납품가 대비, M06과 같은 도우미 |
| 소득세율 | % | 15 | M06과 같은 도우미 |

- 판매가 입력 즉시 "납품가 ○원 (판매가 × (1 − 수수료율))"을 입력칸 아래에 표시.

## 계산 (엔진 그대로)

- 납품가 = 판매가 × (1 − 수수료율)
- 광고비·기타비용 = 납품가 × 각 비율
- 부가세 = (납품가 − 매입가 − 포장비 − 광고비 − 기타비용) ÷ 11
- 비용 합계 = 매입가 + 포장비 + 광고비 + 기타비용 + 부가세 (수수료 제외)
- 세전 순이익 = 납품가 − 비용 합계, 순이익률은 납품가 기준
- 최대광고비 = 세후 순이익 + 광고비
- 최대광고비 비율: **판매가 기준을 대표값**, 납품가 기준은 참고 / 최저 목표 광고수익률 = 판매가 ÷ 최대광고비 × 100

## 결과

- lead: "1개 납품하면 세금까지 빼고 남는 돈은"
- big: 세후 순이익 (+ 납품가 기준 세후 순이익률)
- rows: 쿠팡 판매가 / 납품가 / 가격마진(납품가 − 매입가, 율) / 포장비 / 광고비 / 기타비용 / 부가세 / 소득세 / **세후 순이익**(total)
- **비용 구조 원형 차트** (rows 위): 납품가 = 100%로 매입가 / 포장비 / 광고비 / 기타비용 / 부가세 / 소득세 / 세후 순이익 비율. 가운데 글자 "세후 순이익률 ○%". 차트 아래 한 줄: "쿠팡 판매가 ○원 중 ○%(○원)는 쿠팡 몫이에요" (`Eltin.donut()`)
- tip (광고 지표): "최대광고비 ○원 · 판매가의 ○% (납품가 기준 ○%) · 최저 목표 광고수익률 ○%"
- tip: "쿠팡 광고 화면의 광고수익률은 판매가 기준이에요. 수수료 35%라면 쿠팡에서 1,000%가 나와도 우리 매출 기준으로는 650% 수준이에요."
- **목표 설계** (접는 칸): 판매가가 정해진 로켓배송 특성상 "목표 최고 매입가"를 먼저 보여주고 "목표 최저 판매가"는 아래에

## 계산 기준과 주의 문구

- 셀러 관점(납품가 기준): 가격마진, 광고비, 기타비용, 부가세, 소득세, 순이익률
- 마켓 관점(판매가 기준): 최대광고비 비율 대표값, 최저 목표 광고수익률
- 주의 문구: M06과 같음 ("판매처 수수료" → "로켓배송 공급률")

## 결정 메모

- 공통 엔진 사용 (마켓수수료는 비용에 넣지 않음)
- 수수료율은 예시 35%, 직접 수정 가능 + 수수료 안내
- 최대광고비 비율은 판매가 기준 대표, 납품가 기준 참고 표시
