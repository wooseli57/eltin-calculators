# M05 메뉴 마진 · M06 메뉴 손익 · E03 상품 손익 사양

상태: 사양 확정 (2026-11-25 채팅). 공통 원칙(연결 계산·주소로 값 넘기기·단계 표시)은 `docs/restructure-2026-11.md`, 월 손익(B07) 쪽 받는 값은 `docs/specs/B-monthly.md`.

## 연결 위치
- 메뉴 마진: M01 → M02 → M03 → M04 메뉴 원가 합계 → **M05 메뉴 마진** → **M06 메뉴 손익** → (B07 월 손익)
- 온라인 상품 마진: E01 또는 E02 → **E03 상품 손익** → (B07 월 손익, 온라인 탭)

## M04 → M05 넘기는 값 (M04에 "다음 단계 →" 추가)
- `name` 메뉴 이름, `cost` 매장 판매 원가(손실 반영 재료비 + 포장비, 원 단위), `dcost` 배달 1건당 비용(M04에서 넣었을 때만)

## M05 메뉴 마진 계산기 (마진 5/6)

### 입력
| 항목 | 기본값 | 비고 |
|---|---|---|
| 메뉴 이름 | (M04에서 받음) | 비워도 됨 |
| 메뉴 원가 | 1,200원 (`cost`) | "자세히 계산 →" M04 |
| 매장 판매가 | 4,500원 | 부가세 포함 가격 |
| 부가세 빼고 계산 | 켜짐 | 체크. 일반과세자 기준(판매가 ÷ 1.1). 안내: "간이과세자는 끄고 보세요(대략)" |
| 배달로도 팔아요 | 꺼짐 | 켜면 아래 칸이 열림 |
| └ 배달 판매가 | 5,000원 | |
| └ 배달앱 수수료율 | 중개 7.8% + 결제 3% | S03과 같은 예시값·칩 재사용, 직접 입력 가능 |
| └ 사장님 부담 배달비 (1건) | 2,900원 (`dcost`가 있으면 그 값) | |
| └ 1건당 메뉴 수 | 2개 | 배달비를 메뉴 수로 나눔 |

### 계산
- 공급가(매장) = 부가세 빼기 켜짐이면 판매가 ÷ 1.1, 꺼짐이면 판매가
- **1개 마진(매장)** = 공급가 − 원가
- 마진율 = 마진 ÷ 공급가, 원가율 = 원가 ÷ 공급가
- 배달: 배달 공급가 = 배달 판매가 ÷ 1.1(또는 그대로), 수수료 = 배달 판매가 × (중개 + 결제)%, 1개당 배달비 = 배달비 ÷ 1건당 메뉴 수
- **1개 마진(배달)** = 배달 공급가 − 원가 − 수수료 − 1개당 배달비

### 결과
- lead: "{메뉴} 1개 팔면 남는 돈은" (매장 기준)
- big: 1개 마진(매장)
- 원그래프: 원가 / 부가세(켜짐일 때) / 남는 돈 (매장 판매가 기준), 가운데 "마진율 ○%"
- rows: 판매가 / 부가세 / 원가 / **1개 마진** / 마진율 / 원가율. 배달 켜짐이면 아래에 배달 판매가 / 수수료 / 1개당 배달비 / **배달 1개 마진** / 배달 마진율
- tip:
  - 원가율 35% 초과: "원가율이 ○%예요. 판매가 계산기(S01)로 목표 원가율에 맞는 가격을 확인해 보세요." (기준값은 참고용임을 계산 기준에 명시)
  - 배달 마진이 매장보다 적으면: "배달로 팔면 1개에 ○원 덜 남아요. 매장만큼 남기려면 배달 판매가는 약 ○원이에요(배달 판매가 계산기 S02)." (매장 마진과 같아지는 배달 판매가를 같은 식으로 역산해 표시)
- 다음 단계 → M06 (`name`, `price`, `margin`, `costrate`(원가율 %), 배달 켜짐이면 `dprice`, `dmargin`)
- [결과 복사] [처음으로]

### 확인용 예시 (기본값)
- 공급가 4,090.9 → 마진 2,891원, 마진율 70.7%, 원가율 29.3%
- 배달: 공급가 4,545.5, 수수료 540, 1개당 배달비 1,450 → 배달 마진 1,355원(반올림)

## M06 메뉴 손익 계산기 (손익 6/6)

### 입력
| 항목 | 기본값 | 비고 |
|---|---|---|
| 메뉴 이름 | (M05에서 받음) | |
| 1개 마진 (매장) | 2,891원 (`margin`) | "자세히 계산 →" M05 |
| 판매가 (매장) | 4,500원 (`price`) | 월 매출 표시용 |
| 월 판매량 (매장) | 900개 | 옆에 작은 글씨 "하루 약 ○개 (월 26일)" |
| 배달 1개 마진·배달 판매가·월 배달 판매량 | (M05에서 배달을 켰을 때만 칸이 보임) 월 배달 판매량 기본 200개 | |
| 월 고정비 | 7,300,000원 | 인건비 + 운영비. 안내: "월 손익 계산기(B07)의 고정비와 같은 값" + "자세히 계산 →" B07 |
| 월 영업일 | 26일 | 하루 판매량 환산용 |

### 계산
- **이 메뉴의 월 공헌이익** = 매장 마진 × 월 판매량 + 배달 마진 × 월 배달 판매량 (고정비를 빼기 전, 이 메뉴가 버는 돈)
- 이 메뉴의 월 매출 = 판매가 × 판매량 + 배달 판매가 × 배달 판매량
- 고정비 감당 비율 = 공헌이익 ÷ 월 고정비
- 이 메뉴만으로 손익분기 판매량 = 월 고정비 ÷ 매장 마진 (개/월), 하루 = ÷ 영업일

### 결과
- lead: "{메뉴}로 한 달에 버는 돈은 (고정비 빼기 전)"
- big: 월 공헌이익
- 막대 또는 원그래프: 월 고정비 중 이 메뉴가 감당하는 부분 / 나머지 (가운데 "고정비의 ○%")
- rows: 월 판매량 (하루 ○개) / 월 매출 / 월 공헌이익 / 고정비 감당 비율 / 이 메뉴만으로 고정비를 다 감당하려면 하루 ○개
- tip: "다른 메뉴까지 더한 가게 전체 이익은 월 손익 계산기에서 확인하세요."
- 버튼: [월 손익으로 →] B07 매장 탭, `matp`=원가율(%)을 원가 줄의 매출 % 값으로 채움. B07 원가 줄 아래 안내: "메뉴 원가율을 가게 전체 원가율로 넣었어요. 메뉴마다 다르면 고쳐 주세요"
- [결과 복사] [처음으로]

### 확인용 예시
- 2,891 × 900 = 2,601,900원 (배달 없음), 월 매출 4,050,000원
- 고정비 감당 2,601,900 ÷ 7,300,000 = 35.6%
- 손익분기 판매량 7,300,000 ÷ 2,891 = 2,525.1 → **올림 2,526개/월, 하루 98개** (판매량은 항상 올림)
- M06은 M05에서 받은 1개 마진(원 단위 정수)으로 계산

## E03 상품 손익 계산기 (손익 2/2)

### E01·E02 → E03 넘기는 값 (E01·E02에 "다음 단계 →" 추가)
- `name` 상품 이름(있으면), `type` direct|rocket, `price` 판매가, `base` 정산 기준가(직접 판매=판매가, 로켓=납품가), `ebt` 1개 세전 이익(엔진 `ebt`, 소득세 빼기 전), 엔진 항목: `buy`(매입가 G), `fee`(마켓 수수료 금액, 직접 판매만), `pack`(포장비 L), `ad`(1개 광고비), `etc`(1개 기타비용), `vat`(1개 부가세)
- 세후 이익이 아니라 **세전 이익**을 쓰는 이유: 소득세는 1년 이익으로 세금 계산기에서 계산하므로 여기서 미리 빼면 두 번 빠짐

### 입력
| 항목 | 기본값 |
|---|---|
| 상품 이름 | (받은 값) |
| 1개 세전 이익 | (받은 값, 없으면 2,000원) "자세히 계산 →" E01 |
| 판매가 | (받은 값, 없으면 20,000원) |
| 월 판매량 | 300개 (하루 약 ○개, 월 30일 기준) |
| 월 고정비 (온라인) | 500,000원 (창고·솔루션 등, "자세히 계산 →" B05 온라인 탭) |

### 계산·결과
- 월 이익 = 1개 세전 이익 × 월 판매량 − 월 고정비
- 손익분기 판매량 = 월 고정비 ÷ 1개 세전 이익 (올림)
- 월 매출 = 판매가 × 월 판매량 (로켓은 납품가 × 월 판매량을 "정산 매출"로 함께 표시)
- lead "{상품}으로 한 달에 남는 돈은", big 월 이익, rows: 월 판매량 / 월 매출 / 1개 세전 이익 × 판매량 / 월 고정비 / **월 이익** / 손익분기 판매량(하루 ○개)
- tip: "부가세는 1개 이익에서 이미 뺐고, 소득세는 빼기 전이에요. 1년 이익으로 세금 계산기(O05)에서 확인하세요."
- 버튼: [월 손익으로 →] B07 온라인 탭. 넘기는 값(월 기준 = 1개 값 × 판매량): `sales`(직접 판매: 판매가 기준, 로켓: 납품가 기준), `mat`(buy), `sell`(fee + pack + etc), `ad`(ad, `adv=1`), `opex`(월 고정비). 부가세(`vat`)는 B07이 부가세 빼기 전 기준이라 넘기지 않음 → B07 결과에 "부가세 빼기 전 이익" 안내로 E03 결과와의 차이 설명
- [결과 복사] [처음으로]

### 확인용 예시
- 2,000 × 300 − 500,000 = 100,000원, 손익분기 250개/월 (하루 약 9개)

## B07 쪽 추가로 받을 값
- `matp`(원가 % → 원가 줄 % 모드로), `sellp`(판매비 %) — M06에서 사용
- E03에서 받는 값은 기존 키(`sales`·`mat`·`sell`·`ad`·`adv`·`opex`)와 같음
