# 계산기 이용 권한: 누구나 / 회원 전용 (2026-11-26 확정)

## 결정
- **회원 전용 30개**: M 메뉴 마진(6) · E 온라인 상품 마진(3) · B 월 마진(8) · R 레시피(8) · G 조색 가이드(5)
- **누구나 34개**: L 인건비(5) · O 운영비(6) · S 판매 응용(10) · A 광고(6) · T 기본 도구(7)
- 회원가입은 무료. 회원 전용 계산기를 안내하는 모든 곳에 **"회원가입은 무료예요"**를 함께 표시
- 계산기 자체는 그대로 무료·저장 없음. 바뀌는 건 "어디서 열 수 있는가"뿐

## 어떻게 막는가 (현실적인 한계 포함)
1. **진짜 잠금은 아임웹이 함**: 회원 전용 계산기를 넣은 아임웹 페이지(메뉴)의 접근 권한을 "로그인한 회원만"으로 설정. 로그인 안 한 손님에게는 아임웹이 로그인/가입 창을 보여줌. (아임웹 관리자의 메뉴·페이지 접근 권한 설정에서. 실제 메뉴 이름은 화면에서 확인)
2. **GitHub 주소로 직접 여는 경우**: 계산기 파일은 GitHub Pages에 공개돼 있어 주소를 알면 열 수 있음. 서버가 없어서 완전히 막을 수는 없음 → 회원 전용 계산기는 **아임웹 안(iframe)에서 열렸을 때만 계산 화면을 보여주고**, 그 밖에서 열리면 안내 화면을 보여줌 (대부분의 손님은 여기서 아임웹으로 이동. 개발 지식이 있는 사람이 일부러 우회하는 것까지는 못 막음. 계산기 내용이 비밀은 아니므로 이 수준으로 충분)

## 코드 탭 작업
1. `docs/calculators.md` 표에 **"이용"** 열 추가 (값: `누구나` / `회원`). `tools/build-calculators.py`가 이 열을 읽어 `data/calculators.json`에 `"access": "free" | "member"` 추가
2. `assets/eltin-calc.js`
   - `SITE.memberPage`: 회원 전용 계산기를 넣은 아임웹 페이지 주소(사용자에게 받기). `SITE.signup`: 아임웹 회원가입 주소
   - `Eltin.init()`에서 `<html data-access="member">`이면 임베드 확인:
     - 아임웹 iframe 안이면(`?embed=1` 이고 `document.referrer` 또는 `location.ancestorOrigins[0]`가 `eltin.imweb.me`) → 그대로 계산기 표시
     - 아니면 → 입력·결과 카드 대신 안내 카드: 🔒 "엘틴 쇼핑몰 회원 전용 계산기예요" / "회원가입은 무료예요. 가입하면 메뉴 마진·월 마진·레시피 계산기 30개를 모두 쓸 수 있어요" / [회원 전용 계산기 열기] → `SITE.memberPage`, [무료 회원가입] → `SITE.signup` (둘 다 새 창). 머리말과 하단 연결은 그대로
     - `SITE.devPreview`가 true면 안내 카드 대신 화면 위에 "회원 전용 (개발 미리보기)" 띠만 표시해 개발·캡처에 지장 없게
   - 회원 전용 30개 파일의 `<html>`에 `data-access="member"` 추가
3. 목록 페이지(`index.html`)
   - 회원 전용 계산기 카드에 🔒 회원 배지, 클릭하면 GitHub 주소가 아니라 `SITE.memberPage`(해당 계산기 위치)로 이동
   - 맨 위 안내 한 줄: "🔒 표시는 엘틴 쇼핑몰 회원 전용이에요. 회원가입은 무료예요."
   - 칩 필터에 "누구나 / 회원" 필터 추가는 선택
4. 연결 흐름: 회원 전용 → 회원 전용 링크는 그대로. 누구나 계산기의 "함께 쓰면 좋은 계산기/다음 단계"가 회원 전용을 가리키면 링크 옆에 🔒 표시
5. 확인: 회원 전용 파일을 (a) 그냥 열기 → 안내 카드, (b) `?embed=1` + 아임웹 referrer 흉내 → 계산 화면, (c) 누구나 계산기는 변화 없음
