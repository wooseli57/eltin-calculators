- `### 세부 분류`: 한 분류 안의 작은 묶음 (판매 응용: 가격 정하기·행사 / 광고: 온라인 광고·매장 홍보)
- `단계` 열: 연결 계산의 단계 표시 (예: `원가 1/6`). 머리말 태그 옆과 목록에 보여줌
- `이용` 열: `누구나` / `회원` (회원 전용은 아임웹 회원만 열 수 있게 함, 회원가입은 무료. 사양: `docs/specs/access.md`)
- `함께 보이기` 열: 이 계산기를 함께 보여줄 다른 분류 글자 또는 연결 단계 태그 (예: `M`이면 메뉴 마진 목록에도 보임, `L01`이면 B04 단계 옆 "자세히 계산" 링크). 파일은 하나
