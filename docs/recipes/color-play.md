# 색 놀이 레시피 (G05 인기 색 레시피·블로그 색놀이 콘텐츠 후보)

상태: **초안** (2026-11-24 R04에서 옮김). 색 자체가 목적인 레시피라 R04(표준 레시피)에서 빼고 여기에 보관합니다. 색소 양은 R01·G05 데이터가 확정되면 채웁니다.

## 1. 아이 놀이 반죽 (식품 재료로 만드는 클레이)
- 대상: 엄마·아이 색소놀이 / 기본 분량: 4색, 약 400g
- 바탕: 반죽 / 색 입힐 양: 100g씩 4덩이

| 재료 | 양 | 메모 |
|---|---|---|
| 중력분 | 200g | |
| 고운 소금 | 60g | 보존을 위해 넣음 |
| 물 | 130~150g | 조절 |
| 식용유 | 15g | |
| 엘틴 식용색소 4색 | R01 확정 후 채움 | 100g씩 나눠 조색 |

만드는 법
1. 밀가루와 소금을 섞고 물과 식용유를 넣어 매끈하게 반죽합니다.
2. 4등분해 색소를 넣고 색이 고르게 될 때까지 주무릅니다.
3. 지퍼백에 넣어 냉장 보관하고 1주일 안에 사용합니다.

주의: **먹는 용도가 아니에요.** 소금이 많이 들어 있어 먹으면 안 되니, 아이가 입에 넣지 않도록 지켜봐 주세요. 식품 재료로 만들어 시판 클레이보다 안심하고 만질 수 있는 놀이 반죽이에요.

## 2. 컬러 슈가 (데코용 색 설탕)
- 대상: 홈베이킹·아이 체험 / 기본 분량: 100g
- 바탕: 설탕 / 색 입힐 양: 100g

| 재료 | 양 | 메모 |
|---|---|---|
| 굵은 백설탕 | 100g | 입자가 굵을수록 예쁨 |
| 엘틴 식용색소 | R01 확정 후 채움 | |

만드는 법
1. 지퍼백에 설탕과 색소를 넣고 색이 고르게 될 때까지 흔들며 주무릅니다.
2. 종이 포일에 얇게 펼쳐 2~3시간 말립니다.
3. 뭉친 부분은 손으로 풀어 밀폐 용기에 보관합니다.

팁: 쿠키나 컵케이크 위에 뿌리면 바로 컬러 데코가 돼요. 아이와 함께하기 좋은 가장 쉬운 색소 놀이예요.
