# 엘틴 레시피 20선 (R04 엘틴 레시피 계산기 데이터)

상태: **초안** (2026-11-24 채팅에서 작성, 같은 날 표준 레시피로 개정). 제과 표준 배합을 기준으로 한 초안이며, 엘틴에서 실제로 만들어 보고 분량·수율을 확정한 뒤 공개합니다.

## 작성 규칙

- **색소는 넣지 않음**: R04는 색소가 없는 표준 레시피만 다룹니다. 색을 입히려면 R01(색소 사용량 계산기)로 이어집니다.
  - 색을 넣는 레시피에는 재료 표 아래에 `색을 넣으려면` 줄을 둡니다: 넣는 단계 / 바탕 종류 / 색 입힐 양.
  - `색 입힐 양`은 기본 분량 기준이며, 계산기에서는 분량을 바꾸면 같이 바뀝니다. R04 화면은 이 바탕 종류와 무게를 R01로 넘깁니다 (`docs/specs/color-flavor-links.md`).
  - 바탕 종류 이름은 `data/color-bases.json`의 목록을 씁니다: 생크림, 버터크림, 머랭, 반죽, 아이싱, 쌀가루, 음료, 젤리, 설탕, 초콜릿.
- **바닐라는 표준 재료로 넣음**: 달걀·유제품의 잡내를 잡기 위해, 달걀이나 유제품이 들어가는 레시피에는 엘틴 퓨어 바닐라 익스트랙을 표준 양으로 넣습니다.
  - 상세페이지 사용 기준: 밀가루 125g당 1tsp(5ml) / 우유·생크림 250ml당 1tsp(5ml) / 버터 225g당 3tsp(15ml) / 달걀 1알당 3tsp(15ml)
  - 달걀 기준은 양이 너무 많아져서(제누아즈 약 30ml) 쓰지 않고, 밀가루·우유·버터 기준 중 **적은 쪽**을 씁니다. 바닐라 맛이 주인공인 레시피(바닐라 파운드·시럽·커스터드·아이스크림)는 예외로 넉넉히 넣습니다.
  - 엘틴 바닐라 익스트랙은 일반적인 바닐라 익스트랙과 같은 방식으로 만든 제품으로 보고 계산합니다.
  - 바닐라 에센스는 음료·생크림·아이스크림처럼 굽지 않는 디저트에 권장합니다 (에센스 상세페이지).
- **바닐라 외 향료(레몬·과일 등)는 넣지 않음**: 표준 맛으로 두고, 향을 바꾸려면 R02(향료 사용량 계산기)로 이어집니다. 해당 레시피에는 `향을 바꾸려면` 줄을 둡니다.
- **양 조절 방식**: 개수 / 틀(1호 기준, R06 크기표) / 무게(g) / 부피(ml) 중 하나. R03과 같은 엔진으로 계산합니다.
- **개수로 세는 재료**(달걀 등): 계산 결과를 반올림하고 g도 함께 표시합니다.
- 재료 표의 `양`은 기본 분량 기준입니다.
- 색 놀이용 레시피(아이 놀이 반죽, 컬러 슈가)는 R04에서 빼고 `docs/recipes/color-play.md`로 옮겼습니다 (G05·블로그 색놀이 콘텐츠용).

## 1. 마카롱 꼬끄
- 대상: 카페·홈베이킹 / 기본 분량: 약 30개 (지름 4cm, 15쌍) / 양 조절: 개수

| 재료 | 양 | 메모 |
|---|---|---|
| 아몬드가루 | 100g | |
| 슈가파우더 | 100g | |
| 달걀흰자 (반죽용) | 37g | |
| 달걀흰자 (머랭용) | 37g | |
| 설탕 | 100g | |
| 물 | 25g | |
| 엘틴 퓨어 바닐라 익스트랙 | 2ml | 흰자 잡내 제거 |

- 색을 넣으려면: 3단계, 완성된 머랭에 / 바탕: 머랭 / 색 입힐 양: 반죽 전체 약 370g

만드는 법
1. 아몬드가루와 슈가파우더를 체 쳐서 반죽용 흰자와 섞어 둡니다.
2. 설탕과 물을 118℃까지 끓여 시럽을 만듭니다.
3. 머랭용 흰자를 거품 내다가 시럽을 가늘게 부으며 단단한 머랭을 만들고, 바닐라를 넣습니다.
4. 머랭을 1의 반죽에 2~3번 나눠 섞어 윤기 나게 만듭니다(마카로나주).
5. 지름 4cm로 짜고 표면이 마를 때까지 20~30분 둔 뒤 150℃에서 12~14분 굽습니다.

팁: 색을 넣을 때는 머랭에 넣어야 고르게 섞여요. 구우면 색이 조금 옅어지니 원하는 색보다 살짝 진하게 맞추세요.

## 2. 버터크림 (이탈리안 머랭)
- 대상: 베이커리·레터링 케이크 / 기본 분량: 약 500g / 양 조절: 무게

| 재료 | 양 | 메모 |
|---|---|---|
| 달걀흰자 | 60g | |
| 설탕 | 120g | |
| 물 | 40g | |
| 무염버터 | 300g | 실온 |
| 엘틴 퓨어 바닐라 익스트랙 | 5ml (1tsp) | |

- 색을 넣으려면: 4단계, 완성된 버터크림을 나눠 담아서 / 바탕: 버터크림 / 색 입힐 양: 약 500g (나눠 담으면 나눈 양)

만드는 법
1. 설탕과 물을 118℃까지 끓입니다.
2. 흰자를 거품 내며 시럽을 가늘게 부어 머랭을 만들고, 미지근해질 때까지 계속 휘핑합니다.
3. 부드러운 버터를 조금씩 넣으며 매끈해질 때까지 휘핑합니다.
4. 바닐라 익스트랙을 넣어 마무리합니다.

팁: 버터크림은 바탕이 약간 노란빛이라 파랑을 넣으면 초록빛이 돌 수 있어요.

## 3. 생크림 아이싱 (케이크용)
- 대상: 베이커리·홈베이킹 / 기본 분량: 1호 케이크 1개분 (약 430g) / 양 조절: 틀

| 재료 | 양 | 메모 |
|---|---|---|
| 생크림 (동물성) | 400g | 차갑게 |
| 설탕 | 32g | 생크림의 8% |
| 엘틴 바닐라 에센스 또는 퓨어 바닐라 익스트랙 | 8ml | 굽지 않으므로 에센스도 좋음 |

- 색을 넣으려면: 2단계, 70% 휘핑했을 때 / 바탕: 생크림 / 색 입힐 양: 약 430g

만드는 법
1. 볼 아래에 얼음물을 받치고 생크림과 설탕을 넣어 휘핑합니다.
2. 70% 정도 올라오면 바닐라를 넣습니다.
3. 아이싱용은 끝이 살짝 휘는 정도(80~90%)까지 휘핑합니다.

팁: 색을 넣은 뒤 오래 휘핑하면 분리될 수 있으니 마지막 단계는 짧게 해주세요.

## 4. 제누아즈 시트
- 대상: 베이커리·홈베이킹 / 기본 분량: 1호 (지름 15cm) 1개 / 양 조절: 틀

| 재료 | 양 | 메모 |
|---|---|---|
| 달걀 | 120g (약 2개) | 개수 재료 |
| 설탕 | 70g | |
| 박력분 | 70g | |
| 무염버터 | 15g | 녹여서 |
| 우유 | 20g | 버터와 함께 데움 |
| 엘틴 퓨어 바닐라 익스트랙 | 3ml | 밀가루 기준 |

- 색을 넣으려면: 3단계, 버터·우유에 섞어서 / 바탕: 반죽 / 색 입힐 양: 반죽 약 295g

만드는 법
1. 달걀과 설탕을 중탕으로 40℃까지 데운 뒤 연한 미색이 될 때까지 휘핑합니다.
2. 체 친 박력분을 넣고 가볍게 섞습니다.
3. 따뜻한 버터·우유·바닐라에 반죽 일부를 섞은 뒤 본 반죽에 넣고 섞습니다.
4. 1호 틀에 붓고 170℃에서 약 25~30분 굽습니다.

## 5. 아이싱 쿠키 (슈가쿠키 + 로열아이싱)
- 대상: 홈베이킹·아이 체험 / 기본 분량: 약 20개 (6cm 틀) / 양 조절: 개수

| 재료 | 양 | 메모 |
|---|---|---|
| 무염버터 | 100g | 실온 |
| 슈가파우더 | 70g | 쿠키용 |
| 달걀 | 30g | |
| 박력분 | 200g | |
| 엘틴 퓨어 바닐라 익스트랙 | 5ml | |
| 슈가파우더 | 250g | 아이싱용 |
| 달걀흰자 | 40g | 아이싱용 (머랭파우더로 대체 가능) |
| 레몬즙 | 5g | 아이싱용 |

- 색을 넣으려면: 4단계, 아이싱을 색별로 나눠서 / 바탕: 아이싱 / 색 입힐 양: 아이싱 약 295g (나눠 담으면 나눈 양)

만드는 법
1. 버터를 풀고 슈가파우더, 달걀, 바닐라 순으로 섞은 뒤 박력분을 넣어 반죽합니다.
2. 5mm 두께로 밀어 1시간 이상 냉장한 뒤 모양 틀로 찍습니다.
3. 170℃에서 10~12분 굽고 완전히 식힙니다.
4. 아이싱 재료를 섞어 되기를 맞추고, 테두리를 그린 뒤 안을 채웁니다.

## 6. 바닐라 컵케이크
- 대상: 홈베이킹·카페 / 기본 분량: 12개 (머핀틀) / 양 조절: 개수

| 재료 | 양 | 메모 |
|---|---|---|
| 무염버터 | 115g | 실온 |
| 설탕 | 150g | |
| 달걀 | 100g (2개) | 개수 재료 |
| 박력분 | 190g | |
| 베이킹파우더 | 6g | |
| 소금 | 1g | |
| 우유 | 120g | |
| 엘틴 퓨어 바닐라 익스트랙 | 7ml | |

- 색을 넣으려면: 2단계 뒤, 반죽을 나눠서 / 바탕: 반죽 / 색 입힐 양: 반죽 약 690g (나눠 담으면 나눈 양)

만드는 법
1. 버터와 설탕을 크림화하고 달걀, 바닐라를 나눠 넣습니다.
2. 가루 재료와 우유를 번갈아 넣어 섞습니다.
3. 머핀틀에 70%씩 나눠 담습니다.
4. 175℃에서 18~20분 굽습니다.

팁: 레인보우 컵케이크로 만들려면 반죽을 6등분(한 색 약 115g)해 색을 넣고, 컵에 색 순서대로 한 숟갈씩 쌓아요. 색소 양은 R01에서 115g 기준으로 계산하세요.

## 7. 백설기 (떡케이크)
- 대상: 떡카페·홈베이킹 / 기본 분량: 1호 (지름 15cm) 1개 / 양 조절: 틀

| 재료 | 양 | 메모 |
|---|---|---|
| 습식 멥쌀가루 | 500g | 소금 간 된 것 |
| 설탕 | 50g | |
| 물 | 50~80g | 가루 상태에 따라 조절 |

- 색을 넣으려면: 2단계, 물 준 쌀가루를 나눠서 / 바탕: 쌀가루 / 색 입힐 양: 약 600g (층별로 나누면 나눈 양)

만드는 법
1. 쌀가루에 물을 조금씩 넣어 손으로 비벼, 쥐었을 때 뭉쳐지는 정도로 맞춥니다.
2. 다시 체에 내립니다.
3. 설탕을 섞고 시루나 틀에 담습니다.
4. 김이 오른 찜기에서 20분 찌고 5분 뜸을 들입니다.

팁: 층마다 색을 다르게 하려면 2단계에서 층 수만큼 나눠 색을 섞은 뒤 각각 체에 내려요.

## 9. 레몬 에이드 시럽

| 재료 | 양 | 메모 |
|---|---|---|
| 설탕 | 500g | |
| 물 | 500g | |
| 레몬즙 | 80g | |

- 색을 넣으려면: 2단계, 식힌 시럽에 / 바탕: 음료 / 색 입힐 양: 약 800ml (블루·핑크 에이드)
- 향을 바꾸려면: 2단계, 식힌 시럽에 / 과일 에이드 / 향 입힐 양: 약 800ml

3. 한 잔: 시럽 40ml + 탄산수 200ml + 얼음.

| 달걀흰자 | 100g | 실온 |
| 설탕 | 100g | |
| 아몬드가루 | 50g | |
| 박력분 | 40g | |

| 엘틴 퓨어 바닐라 익스트랙 | 3ml | 흰자 잡내 제거 |

만드는 법

| 소금 | 한 꼬집 | 단맛을 끌어올림 |

에센스로 만들 때: 바닐라 익스트랙 대신 **엘틴 바닐라 에센스 12~15ml** (에센스 상세페이지 기준 설탕 200g·물 200ml에 5~6ml)

만드는 법
1. 냄비에 설탕과 물을 1:1로 넣고, 젓지 않은 채 중불에서 설탕이 완전히 녹을 때까지 끓입니다.
2. 설탕이 다 녹으면 불을 끄고 식힙니다.
3. 미지근하게 식었을 때 바닐라 익스트랙(또는 에센스)과 소금을 넣고 가볍게 섞습니다.
4. 소독한 유리병에 담아 냉장 보관합니다.

팁: 열을 가하지 않고 마지막에 넣어야 천연 바닐라 향이 날아가지 않아요. 익스트랙 바닥의 검은 알갱이는 바닐라 씨앗이라 그대로 써도 됩니다.
